도면 확대 인쇄

도면 PDF에서 필요한 그림만 골라 크게 확대하고, 작업번호·동그라미 번호·형광펜 표시를 얹어 한 장씩 인쇄합니다.

  • 운영체제Windows 10 / 11
  • 성격독립 실행형 도면 편집·출력 도구 (아이칸 작업지시서 관리자와는 별도 프로그램)
처음 사용하는 분빠른 시작 8단계도구를 익히는 분영역·문구·번호·형광펜인쇄가 이상할 때자주 묻는 문제

CHAPTER 01

개요

1.1 무엇을 하는 프로그램인가

도면 PDF에서 필요한 그림 부분만 골라 크게 확대해서 한 장씩 인쇄하는 프로그램입니다. 확대한 그림 위에 작업번호, 동그라미 번호(①~⑮), 형광펜 표시를 얹어서 현장에서 보기 좋은 출력물을 만듭니다.

1.2 주요 특징

특징 설명
원본 보존 원본 PDF는 절대 수정하지 않습니다. 편집 내용은 별도의 작업 파일(.pdfregions)에 저장됩니다.
영역 1개 = 출력 1장 인쇄 영역을 세 개 만들면 세 장이 출력됩니다. 영역마다 배율을 따로 정할 수 있습니다.
사각형·다각형 영역 L자·ㄷ자 상판처럼 필요한 부분만 꼭짓점으로 둘러싸면 바깥은 흰색으로 지워져 출력됩니다.
표시 도구 작업번호 문구, 동그라미 번호 ①~⑮, 형광펜 선, 형광 사각형, 형광 다각형.
바로 인쇄 PDF 뷰어를 거치지 않고 프로그램에서 프린터로 바로 보냅니다. 실제 크기 100%·단면·용지 방향이 자동으로 맞춰집니다.
고화질 출력 일반 PDF는 원본 선·글자를 그대로(벡터) 확대해 프린터 해상도로 선명하게 나오고, 스캔 도면은 자동으로 바탕을 하얗게 보정합니다.
키보드 중심 거의 모든 기능에 단축키가 있으며 한/영 상태나 Caps Lock과 관계없이 동작합니다.

1.3 용어

용어 뜻
원본 PDF 불러온 도면 PDF 파일. 읽기만 합니다.
인쇄 영역 출력할 부분을 감싼 사각형 또는 다각형. 영역 하나가 출력 한 장입니다.
배율 원본 대비 출력 확대 비율(%). 영역마다 따로 가집니다.
개체 페이지 위에 만든 영역·문구·번호·형광 표시를 통틀어 부르는 말.
작업 파일 영역·문구·형광 표시를 저장한 .pdfregions 파일.
인쇄용 PDF 영역마다 한 장씩, 확대·표시가 반영되어 만들어진 출력 전용 PDF.
pt (포인트) 크기 단위. 1pt = 1/72인치 ≈ 0.353mm. 원본 도면 기준 크기입니다.

CHAPTER 02

설치와 실행

2.1 폴더 구성 (배포본)

도면확대인쇄_v2.6/
├─ 빌드.bat          ← 처음 한 번 더블클릭해서 실행 파일을 만듭니다
├─ build.py
├─ 빠른시작.txt
├─ 사용방법.md
├─ 소스/             ← 프로그램 소스 (app.py, core.py, ui.py, winprint.py, requirements.txt, README.md)
└─ 라이선스/

2.2 처음 설치 (한 번만)

  1. Python 3.11 이상이 설치된 PC에서 빌드.bat을 더블클릭합니다.

  2. 필요한 부품 설치 → 아이콘 생성 → 실행 파일 생성 순서로 진행되며 1~3분 걸립니다.

  3. 끝나면 같은 폴더에 도면확대인쇄.exe와 _internal 폴더가 생깁니다.

  4. 이후로는 도면확대인쇄.exe만 실행하면 됩니다.

주의

실행 파일을 다른 곳으로 옮길 때는 _internal 폴더를 포함한 폴더 전체를 함께 옮겨야 합니다.

Python이 없으면 빌드.bat이 "Python is not installed" 안내를 띄우고 멈춥니다. python.org에서 Python을 설치한 뒤 다시 실행하세요.

2.3 실행하는 방법

방법 동작
도면확대인쇄.exe 더블클릭 빈 화면으로 시작합니다.
PDF 파일을 도면확대인쇄.exe 아이콘에 끌어다 놓기 그 PDF가 열린 상태로 시작합니다. 여러 개를 한 번에 놓아도 됩니다.
.pdfregions 파일을 아이콘에 끌어다 놓기 그 작업이 열린 상태로 시작합니다.
실행 중인 창 위로 PDF를 끌어다 놓기 PDF가 목록에 추가됩니다 (.pdfregions는 작업 열기).

2.4 시작 화면

PDF를 열기 전에는 가운데에 아이콘과 PDF 추가 (Ctrl+O) 버튼, 3단계 안내가 표시됩니다.

  1. R 인쇄 영역(Shift+R 다각형)으로 그림 감싸기

  2. T 작업번호 · L 형광펜 · N ①②③

  3. Ctrl+P 미리보기 후 바로 인쇄

CHAPTER 03

화면 구성

3.1 상단바

항목 기능 단축키
PDF 추가 도면 PDF를 불러옵니다 (여러 개 선택 가능). Ctrl+O
작업 열기 저장해 둔 작업 파일(.pdfregions)을 엽니다. Ctrl+Shift+O
저장 작업을 저장합니다. 한 번 저장한 뒤로는 바로 덮어씁니다. Ctrl+S
↶ / ↷ 실행 취소 / 다시 실행 Ctrl+Z / Ctrl+Y
출력 예정 N장 · 용지 지금 만들어 둔 영역 수(= 출력 장수)와 용지를 보여줍니다. —
단축키 단축키 전체 목록 창을 엽니다. F1

버튼에 마우스를 올리면 설명과 단축키가 말풍선으로 표시됩니다.

3.2 도구 막대 (왼쪽 세로)

위에서부터 선택(V) · 영역(R) · 다각영역(Shift+R) · 문구(T) · 번호(N) · 형광펜(L) · 사각형(M) · 다각형(P) · 화면(H) 입니다. 선택된 도구는 파란색으로 표시되며, 상태표시줄 왼쪽에 도구 이름·단축키와 사용법이 나옵니다. 각 도구는 5장에서 자세히 설명합니다.

3.3 PDF·원본 페이지 목록 (왼쪽)

  • 불러온 PDF와 각 페이지가 트리로 표시됩니다. 오른쪽 숫자는 그 PDF/페이지에서 출력될 장수입니다.
  • 영역이 있는 페이지는 파란 글씨, 없는 페이지는 흐린 글씨와 —로 표시됩니다.
  • PDF 이름에 5자리 작업번호(예: 24117 또는 24117-24118)가 있으면 이름 앞에 붙여 보여줍니다 (이미 이름이 번호로 시작하면 생략).
  • 아래 PDF 추가, 빼기 버튼이 있습니다. 빼기는 확인을 거치며 원본 파일은 지우지 않습니다.
  • 맨 아래 안내: 출력 순서는 PDF 목록 → 원본 페이지 → 영역 번호 순서입니다.

3.4 작업 캔버스 (가운데)

  • 위쪽 머리글에 PDF 이름, 페이지 번호, 원본 크기(mm), 파일 위치가 표시되고 오른쪽에 ◀ 현재/전체 ▶ 페이지 이동 버튼이 있습니다.
  • 가운데 어두운 바탕 위에 도면 페이지가 표시되며, 여기서 영역과 표시를 만듭니다.
  • 작업 결과(영역 추가, 삭제, 복사 등)는 캔버스 위쪽에 잠깐 알림으로 표시됩니다.

3.5 오른쪽 설정 패널

카드 형태이며 지금 쓰는 도구나 선택한 개체에 필요한 카드만 나타납니다.

카드 언제 보이나 내용
인쇄 설정 항상 용지, 배율, 적용 버튼, 자동 축소
작업번호 · 문구 문구 도구(T) 또는 문구 선택 시 문구 입력칸, 서식 프리셋, 글자색, 크기, 굵게, 번호 +1
형광 표시 형광펜(L)·사각형(M)·다각형(P) 또는 형광 표시 선택 시 형광색, 농도, 펜 굵기
동그라미 번호 번호 도구(N) 또는 번호 선택 시 ①~⑮ 버튼, 색, 크기, 다음 번호 자동, 속 채움
이 페이지 개체 항상 현재 페이지의 모든 개체 목록과 순서·복제·삭제 버튼

개체를 선택하면 카드 제목 옆에 "선택 영역에 적용" / "선택 문구 편집 중" / "선택 형광 편집 중" / "선택 형광펜 편집 중" / "선택 번호 편집 중" 표시가 붙고, 그 카드에서 바꾼 값이 선택한 개체에 바로 반영됩니다.

CHAPTER 04

빠른 시작 — 기본 작업 흐름

  1. PDF 추가 (Ctrl+O) — 또는 PDF를 창 위로 끌어다 놓습니다.

  2. 왼쪽 목록에서 PDF와 페이지를 고릅니다 (PgDn / PgUp으로 넘기기).

  3. 인쇄 영역 R — 그림과 치수선을 감싸도록 드래그합니다. 드래그하는 동안 실제 인쇄 크기(mm)가 보입니다. 필요한 부분만 잘라야 하면 다각형 영역 Shift+R 로 꼭짓점을 찍습니다.

  4. 배율 — 오른쪽 배율 칸에 숫자를 넣거나 100/130/160/200 버튼, 또는 , . 키로 조절합니다.

  5. 작업번호 T — 번호를 입력하고 그림 위를 클릭합니다.

  6. 형광펜 L — 시작점과 끝점을 클릭해 선을 긋고, 동그라미 번호 N 으로 선 옆에 ①②③을 붙입니다.

  7. 인쇄 Ctrl+P — 미리보기에서 프린터를 확인하고 Enter를 누르면 바로 인쇄됩니다.

  8. 다음에 이어서 고치려면 작업 저장 Ctrl+S.

5.1 선택 / 이동 — V

이미 만든 개체를 고르고, 옮기고, 크기를 바꾸는 도구입니다.

조작 결과

빈 곳 클릭 선택 해제

모서리·변의 흰 점 드래그 크기 조절 (사각형 영역, 형광 사각형·다각형)

다각형 영역의 꼭짓점 점 드래그 꼭짓점 하나씩 수정 (Shift: 이웃 꼭짓점과 수평/수직 맞춤)
문구 더블클릭 / F2 / Enter 문구를 그 자리에서 고치기

개체가 겹쳐 있을 때는 위에 그려진 표시(문구·번호·형광)가 먼저 선택되고, 영역끼리 겹치면 더 작은 영역이 선택됩니다. 원하는 개체가 잘 안 잡히면 Tab으로 차례대로 고르거나 오른쪽 이 페이지 개체 목록에서 고르세요.

5.2 인쇄 영역 — R

출력할 부분을 사각형으로 감쌉니다. 영역 하나가 출력 한 장입니다.

  • 드래그해서 영역을 만듭니다. 드래그하는 동안 커서 옆에 인쇄 210×120mm · 160% 처럼 실제 인쇄 크기와 배율이 표시되고, 용지를 넘으면 (용지 맞춤)이 붙은 주황 표시로 바뀝니다.
  • 새 영역에는 오른쪽 배율 칸의 현재 값이 들어갑니다.
  • 만든 직후 그 영역이 선택된 상태가 되므로, 바로 배율을 바꾸면 그 영역에 적용됩니다.
  • 드래그하지 않고 클릭만 하면 그 자리의 기존 개체를 선택합니다.
  • 영역 왼쪽 위에는 이름표가 붙습니다: 출력 순번장 배율% (예: 3장 160%).

  2. 캔버스로 마우스를 옮기면 놓일 모습이 미리 보입니다.

5.5 동그라미 번호 — N

형광펜 선 옆 등에 ①~⑮ 번호를 붙이는 도구입니다.

  • 클릭한 자리가 동그라미의 중심이 됩니다. 마우스를 따라 다음에 놓일 번호가 미리 보입니다.
  • 오른쪽 동그라미 번호 카드의 ①~⑮ 버튼으로 번호를 고릅니다.
  • 놓을 때마다 다음 번호(기본 켜짐): ① 놓고 → ② 놓고 → … 자동으로 넘어갑니다. ⑮에서는 더 넘어가지 않습니다.
  • 숫자키로 바로 고르기: 7 → ⑦. 1을 누르고 0.9초 안에 0~5를 누르면 ⑩~⑮.
  • [ ]: 이전 / 다음 번호.
  • 이미 놓은 번호는 버튼이 초록색으로 바뀌고, 카드 아래에 "이 페이지에 놓은 번호"가 나열됩니다. 같은 번호를 또 놓으면 겹친다는 알림이 뜹니다 (놓는 것은 허용됩니다).
  • 색: 빨강·검정·초록·파랑 / 크기: 동그라미 지름 8~80pt (기본 22pt) / 속 채움: 색 원 안에 흰 숫자.
  • 기본 모양은 흰 바탕 동그라미라 형광펜이나 도면 선 위에 놓여도 숫자가 잘 읽힙니다.
  • 놓은 번호는 V로 선택한 뒤 숫자키로 번호를 바꾸고, 방향키로 옮기고, 카드에서 크기·색을 고칠 수 있습니다.

참고

번호 도구(N)가 선택되어 있거나 번호를 선택한 상태에서는 숫자키가 번호를 고르고, [ ]가 이전/다음 번호가 됩니다. 다른 상황에서는 숫자 1~4가 색, [ ]가 형광펜 굵기입니다.

5.7 형광 사각형 — M

  • 만든 직후에는 선택되지 않으므로, 색을 바꾸면 다음 사각형에 적용됩니다.
  • V로 선택하면 모서리 점으로 크기를 조절할 수 있습니다.

5.8 형광 다각형 — P

개체 선택과 편집

7.1 선택한 개체와 설정 카드의 연동

개체를 선택하면 그 개체의 값(배율, 문구 내용·크기·색, 형광색·농도·굵기, 번호·크기·색)이 오른쪽 카드에 불러와지고, 카드에서 값을 바꾸면 선택한 개체에 바로 반영됩니다. 같은 개체를 연속으로 고친 것은 실행 취소 한 번으로 되돌아갑니다.

참고

선택한 개체의 값은 다음에 새로 만들 개체의 기본값도 됩니다. 예를 들어 24117 문구를 선택하면 문구 입력칸에도 24117이 들어갑니다.

7.2 이동·크기·미세 조정

  • 드래그로 이동, 흰 점으로 크기 조절 (5.1).
  • 방향키로 1pt, Shift+방향키로 10pt씩 이동. 연속 이동은 실행 취소 한 번으로 묶입니다.
  • 아무것도 선택하지 않은 상태에서 방향키를 누르면 화면이 스크롤됩니다.

10.3 바로 인쇄가 보장하는 것

  • 실제 크기 100%: 프로그램이 프린터의 실제 용지 크기와 인쇄 불가 여백을 읽어서 정확한 크기로 놓습니다. PDF 뷰어처럼 "페이지에 맞춤"으로 줄어드는 일이 없습니다.
  • 단면 고정: 프린터 기본값이 양면이어도 단면으로 인쇄합니다.
  • 용지·방향 자동: A4/A3, 가로/세로를 작업 설정에 맞춰 지정합니다. 드라이버가 방향을 무시하면 프로그램이 그림을 돌려서 맞춥니다.
  • 고해상도: 프린터 해상도(최대 600dpi)로 보냅니다.
  • 프린터가 해당 용지(예: A3)를 지원하지 않으면 "이 프린터 용지가 A3 가로보다 작습니다" 안내와 함께 인쇄를 취소합니다. 종이가 반쯤 나오는 일은 없습니다.
  • 인쇄는 별도 작업으로 처리되므로, 프린터 드라이버에 문제가 생겨도 편집 창은 멈추지 않습니다.

참고

바로 인쇄는 Windows에서만 됩니다. 설치된 프린터가 없으면 안내가 표시되고 인쇄 버튼이 비활성화되며, PDF로 저장은 그대로 쓸 수 있습니다.

10.4 PDF로 저장과 순서표

  • 기본 파일 이름: 첫 PDF 이름의 작업번호를 따서 24117-24118_확대인쇄.pdf (번호가 없으면 원본 이름 + _확대인쇄.pdf).
  • 저장 위치: 처음엔 원본 PDF 폴더, 이후엔 마지막으로 저장한 폴더.
  • 같은 이름으로 .순서표.html 이 함께 저장됩니다. 출력 순번, PDF, 원본 페이지, 영역 번호, 실제 배율, 확인 체크칸이 표로 정리되어 있어 출력물을 정리할 때 씁니다.
  • 원본 PDF 자리에 덮어쓰는 것은 막혀 있습니다.
  • 바로 인쇄용 임시 PDF는 Windows 임시 폴더에 만들어지고 하루가 지나면 자동으로 지워집니다.

16.1 프로그램이 기억하는 설정

다음 실행 때도 그대로 유지됩니다.

  • 용지, 배율(새 영역 기본값), 자동 축소
  • 문구 내용·서식·크기·색·굵게, 번호 +1
  • 형광색, 농도, 펜 굵기
  • 동그라미 번호 크기·색·속 채움·다음 번호 자동
  • 출력 화질·선 진하게·스캔 보정
  • 마지막으로 쓴 프린터
  • 창 크기와 위치(최대화 여부)
  • 마지막으로 PDF를 연 폴더, 인쇄용 PDF를 저장한 폴더

CHAPTER 17

문제 해결 (FAQ)

단축키가 안 먹어요.

작업번호 입력칸이나 숫자 칸에 커서가 있으면 글자가 입력됩니다. Esc를 누르거나 캔버스를 한 번 클릭한 뒤 다시 누르세요.

인쇄물이 작게 나와요 / 잘려요.
  • 프로그램의 인쇄 버튼으로 바로 인쇄하면 항상 실제 크기로 나옵니다.
  • PDF로 저장해서 다른 뷰어로 인쇄할 때는 반드시 실제 크기(100%) 를 고르세요. "페이지에 맞춤"이면 줄어듭니다.
  • 배율이 용지를 넘으면 자동 축소(주황 이름표)됩니다. 그대로 크게 뽑고 싶으면 A3를 쓰거나 영역을 나누세요.
"이 프린터 용지가 A3 가로보다 작습니다"가 떠요.

그 프린터가 A3를 지원하지 않거나 A3 용지가 설정되지 않은 것입니다. A3 프린터를 고르거나 용지를 A4로 바꾸세요.

작업 파일을 열 때 "원본 PDF를 찾지 못했습니다" / "원본이 바뀌었습니다"가 떠요.

작업 파일은 원본 PDF의 위치와 내용을 확인합니다. 원본을 원래 폴더·이름으로 되돌리세요. 원본이 실제로 새 버전으로 바뀌었다면 PDF를 새로 추가해서 작업해야 합니다.

형광 아래 글씨가 안 보일까 걱정돼요.

형광은 곱하기 방식이라 검정 선·글자는 형광 아래에서도 검정 그대로 나옵니다. 농도를 낮추면 더 연해집니다.

스캔 도면이 너무 하얗게 날아가요 / 잡티가 남아요.

미리보기에서 스캔 보정을 끄면 원본 색 그대로 나옵니다. 흐린 선만 진하게 하려면 선 진하게를 켜세요.

보통 PDF인데 흐리게 나와요.

도면 자체가 회색 선으로 그려진 경우입니다. 미리보기에서 선 진하게를 켜세요.

이미 그은 형광펜 선이 굵기를 바꿔도 안 바뀌어요.

[ ]와 굵기 칸은 다음에 그을 선의 설정입니다. 이미 그은 선은 V로 선택한 뒤 [ ]로 바꾸세요.

동그라미 번호가 ⑮에서 안 넘어가요.

번호는 ①~⑮까지입니다. ⑮ 다음은 같은 번호가 계속 놓이니 다른 번호를 직접 고르세요.

바탕화면 아이콘이 예전 그림이에요.

Windows가 아이콘을 저장해 두었기 때문입니다. 바로가기를 지우고 다시 만드세요.

실행 파일을 다른 PC로 옮겼더니 안 켜져요.

_internal 폴더를 함께 옮겨야 합니다. 폴더째 복사하세요.

19.2 동작 방식 요약

  • 원본 PDF는 메모리로 읽어서 열므로 원본 파일을 잠그지 않습니다.
  • 인쇄용 PDF 만들기와 바로 인쇄는 별도 프로세스에서 실행됩니다. 무거운 작업이나 드라이버 문제가 편집 창을 멈추지 않습니다.
  • 벡터 출력: 원본 페이지를 그대로 넣고 확대·배치합니다. 형광은 곱하기 방식의 벡터 도형, 문구·번호는 600dpi 투명 이미지, 영역 밖은 흰색으로 덮습니다.
  • 스캔 출력: 영역만 300dpi로 만들어 잡티 제거 → 색별 레벨 보정 → (선 진하게 시) 감마 → 언샤프 순서로 보정합니다.
  • 바로 인쇄: 페이지를 최대 600dpi로 띠 단위로 나눠 그려서 프린터로 보냅니다. 메모리 사용이 일정합니다.

19.3 점검 모드

도면확대인쇄.exe --self-test <샘플.pdf> <결과폴더>

결과 폴더의 result.json에 {"ok": true}가 나오면 실행 파일이 정상입니다. 프린터 호출이나 원본 변경은 없습니다.
