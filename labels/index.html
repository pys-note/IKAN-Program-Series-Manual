USER MANUAL · v2

아이칸 라벨 출력기

아이라벨 CL920 라벨지(A4·20칸)에 現場名·ITEM·色·SIZE·號室 제품 라벨을 블루·레드로 채워 바로 인쇄합니다.

  • 문서 기준 버전v2 (행 순서 바꾸기 · 장별 시작 칸 지정 포함)
  • 사용 라벨지아이라벨 CL920 (A4, 20칸) 전용
  • 대체하는 기존 방식엑셀 라벨 양식 파일 (도쿄 블루라벨 / 오사카 레드라벨 시트)
처음 사용하는 분라벨 내용 입력하기남은 라벨지가 있을 때장별 시작 칸 지정라벨이 밀려 찍힐 때정렬 테스트로 위치 보정

CHAPTER 01

프로그램 개요

아이칸 라벨 출력기는 아이라벨 CL920 라벨지에 주식회사 아이칸 제품 라벨을 찍는 전용 프로그램입니다. 기존에는 엑셀에 도형으로 그려진 라벨을 하나씩 복사해서 고쳐 썼지만, 이 프로그램은 표에 내용만 입력하면 양식이 자동으로 채워지고 A4 라벨지 칸에 맞춰 바로 인쇄됩니다.

CHAPTER 03

화면 구성

화면은 크게 상단 바, 왼쪽 입력 영역, 오른쪽 미리보기 영역 세 부분입니다. (창 너비가 좁으면 입력 영역이 위, 미리보기가 아래로 배치됩니다.)

3-1. 상단 바

버튼 기능
사용법 간단한 사용법 안내 창을 엽니다
작업 저장 현재 입력 내용을 JSON 파일로 내려받습니다
불러오기 저장해 둔 JSON 작업 파일을 엽니다
정렬 테스트 인쇄 칸 위치 확인용 테스트 시트를 인쇄합니다
인쇄 (Ctrl+P) 입력한 라벨을 인쇄합니다

3-2. 왼쪽 — 라벨 내용 입력

  • 새 행 색상: 새로 추가되는 행의 기본 라벨색 (블루 / 레드)
  • 엑셀에서 붙여넣기: 엑셀 데이터 일괄 입력 창
  • 전체 블루 / 전체 레드: 모든 행의 라벨색을 한 번에 변경
  • 전체 비우기: 모든 행 삭제 (되돌리기 가능)
  • 입력 표: 라벨 한 종류당 한 행
  • + 행 추가: 표 맨 아래에 빈 행 추가
  • 하단 상태 표시줄: 총 라벨 장수 · 블루 장수 · 레드 장수 · 시트(A4) 매수 · 자동 저장 상태

3-3. 오른쪽 — 인쇄 미리보기

  • 옵션 줄: 색상별 시트 나누기 · 바깥 테두리 · 색 번짐 · 보정 X / Y
  • 시작 칸 안내 줄: 이어 쓰는 장 요약, 모두 처음 칸부터 버튼
  • 시트 미리보기: A4 가로 한 장씩, 실제 인쇄 배치 그대로 표시
  • 각 장 위에 n / 전체 매, 색상 표시, 그 장의 라벨 장수, 시작 칸 표시

4-1. 라벨 한 장의 구성

구분 항목 비고
고정 (양식에 인쇄됨) 現場名, ITEM, 色, SIZE, 號室, (주) 아이칸 입력하지 않음

4-2. 글꼴과 크기 (기존 엑셀 양식과 동일)

요소 크기 굵기
머리글 (現場名 · ITEM · 色 · SIZE · 號室) 7pt 보통
입력값 (현장명 · ITEM · 色 · SIZE · 號室) 8pt 굵게
No. (우측 하단 번호) 8pt 굵게
(주) 아이칸 6pt 굵게
  • 글꼴: 맑은 고딕 (일본어 글자가 없을 경우 Yu Gothic / Meiryo로 자동 대체)
  • 칸 위치·선 굵기는 기존 엑셀 도형 좌표를 그대로 mm로 환산해 재현했습니다.

4-3. 글자 자동 맞춤

  • 현장명: 칸을 넘치면 글자가 6.5pt까지 줄어듭니다. 그래도 길면 2줄로 접히며, 두 줄 길이가 고르게 나뉘도록 줄바꿈합니다. (필요하면 4pt까지 더 줄어듦)
  • ITEM · 色 · SIZE · 號室 · No.: 칸을 넘치면 한 줄을 유지한 채 4.5pt까지 줄어듭니다.
  • 미리보기와 인쇄물은 같은 방식으로 계산되므로, 미리보기에서 보이는 그대로 인쇄됩니다.

CHAPTER 05

라벨 내용 입력하기

5-1. 입력 표의 열

열 내용 입력 예 비고
# 행 번호 + ⠿ 순서 손잡이 — 자동
색 라벨 바탕색 칩 — 클릭해서 블루 ↔ 레드
現場名 (현장명) 현장 이름 田畑邸(堺) 이전 입력값 자동완성
ITEM 품목 구분 V, K, U, BG 선택 목록 제공, 대문자 변환
色 (색상코드) 자재 색상 코드 RU657, CT402 이전 입력값 자동완성, 대문자 변환
SIZE 치수 1810*600 1810x600도 자동 변환
號室 (호실) 호실 403 비워도 됨
No. (우측하단) 라벨 우측 하단 번호 2097-1 작업/주문 번호 등
매수 같은 라벨 장수 1 ~ 999 비우거나 0이면 1장
(버튼) ⧉ 복제 / ✕ 삭제 —

참고

빈 행은 인쇄되지 않습니다. 현장명·ITEM·色·SIZE·號室·No. 중 하나라도 입력된 행만 라벨이 됩니다.

5-2. 기본 입력 흐름

  1. 표의 現場名 칸을 클릭하고 현장명을 입력합니다.

  2. Tab으로 오른쪽 칸(ITEM → 色 → SIZE → 號室 → No. → 매수)으로 이동하며 입력합니다.

  3. Enter를 누르면 같은 열의 아래 행으로 내려갑니다. - 마지막 행에서 Enter를 누르면 새 행이 자동으로 추가됩니다. 새 행의 라벨색은 바로 위 행과 같습니다.

  4. 입력하는 즉시 오른쪽 미리보기에 반영됩니다.

5-3. 자동완성 (선택 목록)

  • ITEM: V · K · U · BG 목록이 나타납니다. 목록에 없는 값도 직접 입력할 수 있습니다.
  • 現場名: 최근 입력한 현장명 최대 80개가 목록으로 나타납니다.
  • 色: 최근 입력한 색상코드 최대 60개가 목록으로 나타납니다.
  • 자동완성 목록은 입력할 때마다 쌓이며, PC에 함께 자동 저장됩니다.

5-4. 입력을 빠르게 하는 기능

기능 방법
윗칸 내용 그대로 복사 칸에서 Ctrl+D
현재 행을 통째로 복제해 아래에 추가 Ctrl+Shift+Enter 또는 ⧉ 버튼
위 행으로 이동 Shift+Enter
위/아래 행으로 이동 (SIZE · 號室 · No. · 매수 칸) ↑ / ↓
엑셀 범위를 표에 바로 붙이기 시작할 칸 클릭 후 Ctrl+V (8장)

참고

現場名 · ITEM · 色 칸은 ↑/↓ 키가 자동완성 목록 선택에 쓰이므로 행 이동은 Enter / Shift+Enter를 사용하세요.

5-5. 매수

  • 같은 내용의 라벨이 여러 장 필요하면 행을 여러 개 만들 필요 없이 매수만 늘리면 됩니다.
  • 매수만큼 라벨이 연속으로 배치됩니다.
  • 최대 999장, 숫자가 아니거나 0이면 1장으로 처리됩니다.

CHAPTER 06

행 관리 — 추가·복제·삭제·순서 바꾸기

6-1. 추가

  • 표 아래 + 행 추가 버튼 → 맨 아래에 빈 행 추가 (라벨색은 '새 행 색상' 설정을 따름)
  • 마지막 행에서 Enter → 같은 색의 새 행 자동 추가

6-2. 복제

  • 행 오른쪽 ⧉ 버튼 또는 Ctrl+Shift+Enter → 그 행과 똑같은 행이 바로 아래에 생깁니다.
  • 같은 현장의 비슷한 라벨(예: 2101-1, 2101-2)을 만들 때 복제 후 다른 부분만 고치면 빠릅니다.

6-3. 삭제

  • 행 오른쪽 ✕ 버튼 → 즉시 삭제, 하단에 되돌리기 알림이 잠깐 표시됩니다.
  • 마지막 남은 행을 지우면 빈 행 하나가 남습니다.

6-4. 순서 바꾸기

라벨은 표의 위→아래 순서대로 1번 칸부터 찍힙니다. 순서를 바꾸는 방법은 두 가지입니다.

① 드래그

  1. 행 번호 왼쪽의 ⠿ 손잡이에 마우스를 올리면 손 모양 커서가 됩니다.

  2. 누른 채로 위아래로 끌면, 놓을 위치에 검은 줄이 표시됩니다.

  3. 원하는 위치에서 놓으면 이동합니다. 이동한 행은 잠깐 노란색으로 반짝입니다.

  4. 목록이 길면 표의 위·아래 끝으로 끌 때 자동으로 스크롤됩니다.

② 키보드

  • 옮길 행의 아무 칸에 커서를 두고 Alt+↑ (한 칸 위로) / Alt+↓ (한 칸 아래로)
  • 커서가 행을 따라가므로 여러 번 눌러 연속으로 옮길 수 있습니다.

CHAPTER 07

라벨 색상 (블루 / 레드)

기능 방법
한 행의 색 바꾸기 행 맨 앞 색 칩 클릭 (블루 ↔ 레드)
새로 추가될 행의 기본 색 상단 새 행 색상 블루 / 레드 선택

엑셀에서 가져오기 (붙여넣기)

8-1. 엑셀에서 붙여넣기 창 사용

  1. 엑셀에서 아래 순서대로 된 열을 범위 선택 후 복사(Ctrl+C)합니다.

    1 2 3 4 5 6 7 8
    現場名 ITEM 色 SIZE 號室 No. 매수 라벨색
  • 뒤쪽 열은 없어도 됩니다. (예: 1~6열만 복사해도 됨)
  • 매수가 비어 있으면 1장
  • 라벨색은 블루 / 레드 (또는 B / R, blue / red, 파랑 / 빨강, 도쿄 / 오사카 등). 비어 있으면 '새 행 색상'을 따릅니다. 2. 프로그램에서 엑셀에서 붙여넣기 클릭 → 입력란에 붙여넣기(Ctrl+V) 3. 필요하면 "기존 내용을 지우고 새로 채우기" 체크

  4. 한 칸짜리 내용을 붙이면 일반 붙여넣기처럼 그 칸에만 들어갑니다.

CHAPTER 10

남은 라벨지 이어 쓰기 — 장별 시작 칸

앞부분을 이미 써 버린 라벨지를 다시 쓸 때, 그 장의 몇 번 칸부터 찍을지 정할 수 있습니다. 장마다 따로 정할 수 있어서, 남은 라벨지 여러 장을 한꺼번에 소진할 수 있습니다.

10-1. 시작 칸 정하기

  1. 미리보기에서 해당 장의 시작할 칸을 클릭합니다. (라벨이 이미 그려진 칸도 클릭 가능)

  2. 그 장은 클릭한 칸부터 라벨이 채워지고, 앞 칸들은 "사용됨" 빗금으로 비워집니다.

  3. 밀려난 라벨은 다음 장으로 넘어갑니다.

10-2. 시작 칸 해제

  • 한 장만 해제: 그 장 제목 오른쪽 n번 칸부터 옆 처음부터 클릭
  • 모든 장 해제: 미리보기 맨 위 모두 처음 칸부터 클릭
  • 전체 비우기를 하면 시작 칸 설정도 모두 초기화됩니다.

10-3. 사용 예

예시

1번 칸부터 3칸을 쓴 라벨지 1장, 앞 5칸을 쓴 라벨지 1장, 새 라벨지 여러 장이 있을 때

  1. 미리보기 1매째에서 4번 칸 클릭
  2. 2매째에서 6번 칸 클릭
  3. 3매째부터는 그대로 (1번 칸부터)
  4. 프린터에 4번부터 쓸 장 → 6번부터 쓸 장 → 새 라벨지 순서로 겹쳐 넣고 한 번에 인쇄

10-4. 주의할 점

  • 시작 칸은 "몇 번째 장인지"에 붙어 있습니다. 시작 칸을 정한 뒤 라벨을 많이 추가·삭제하거나 매수를 바꾸면 장 구성이 달라져서, 이어 쓸 라벨지가 의도와 다른 장에 걸릴 수 있습니다. → 내용 입력을 모두 마친 뒤, 인쇄 직전에 시작 칸을 지정하는 것을 권장합니다.
  • '색상별 시트 나누기'를 켠 경우, 장 번호는 블루 장들 → 레드 장들 순서로 이어집니다. (예: 블루 2장, 레드 1장이면 레드 장은 3매째)
  • 프린터에 넣는 라벨지 순서와 방향이 미리보기 장 순서와 같아야 합니다.

CHAPTER 13

프린터 위치 보정 — 정렬 테스트 인쇄

프린터마다 종이를 끌어들이는 위치가 조금씩 달라서, 라벨이 칸에서 몇 mm 밀려 찍힐 수 있습니다. 처음 사용할 때 한 번 맞춰 두세요.

13-1. 보정 순서

  1. 상단 정렬 테스트 인쇄 클릭

  2. 일반 A4 용지에 인쇄합니다. (인쇄 설정은 12장과 동일) - 20칸 위치에 칸 테두리, 가운데 십자선, 칸 번호(1~20) 가 찍힙니다.

  3. 인쇄한 종이를 빈 라벨지 위에 겹쳐 빛에 비춰 봅니다.

  4. 찍힌 칸이 라벨 칼선보다 - 왼쪽으로 밀렸으면 → 보정 X에 +값 (예: 1mm 왼쪽으로 밀림 → 1) - 오른쪽으로 밀렸으면 → 보정 X에 −값 - 위로 밀렸으면 → 보정 Y에 +값 - 아래로 밀렸으면 → 보정 Y에 −값

  5. 다시 정렬 테스트 인쇄로 확인하고, 맞을 때까지 반복합니다.

13-2. 참고

  • 보정값은 이 PC의 이 브라우저에 저장됩니다. 다른 PC·프린터에서는 따로 맞춰야 합니다.
  • 작업 파일을 불러오기 해도 현재 PC의 보정값은 바뀌지 않고 유지됩니다. (보정은 PC·프린터 고유 설정이기 때문)
  • 정렬 테스트 인쇄에도 보정값이 적용되므로, 보정 후 결과를 바로 확인할 수 있습니다.
  • 바탕색이 가장자리에서 살짝 모자라 보이면 색 번짐을 조금 늘리세요 (예: 0.8~1.0mm).

CHAPTER 14

저장·불러오기와 자동 저장

14-1. 자동 저장

  • 입력·옵션 변경 내용은 입력할 때마다 자동 저장됩니다. 하단 오른쪽에 "자동 저장됨"이 표시됩니다.

  • 자동 저장은 브라우저 안에 보관됩니다. 따라서
  • 다른 PC, 다른 브라우저(엣지 ↔ 크롬), 파일 위치를 옮긴 경우에는 보이지 않습니다.
  • 브라우저 인터넷 사용 기록(사이트 데이터)을 지우면 함께 지워집니다.
  • 시크릿(InPrivate) 창에서는 저장되지 않을 수 있습니다. 이때 하단에 "이 환경에선 자동 저장이 안 돼요 — '작업 저장'을 써주세요"가 표시됩니다.

14-2. 작업 저장 (파일로 보관)

  • 상단 작업 저장 → 아이칸라벨_YYYYMMDD_HHMM.json 파일이 내려받기 폴더에 저장됩니다.
  • 예: 아이칸라벨_20261027_1430.json
  • 저장 내용: 모든 행(색·현장명·ITEM·色·SIZE·號室·No.·매수), 인쇄 옵션, 장별 시작 칸
  • 용도: 작업 보관, 다른 PC로 옮기기, 재출력용 백업

14-3. 불러오기

  • 상단 불러오기 → 저장해 둔 .json 작업 파일 선택
  • 현재 표 내용이 파일 내용으로 교체됩니다. (실수했으면 하단 알림의 되돌리기)
  • 파일의 현장명·색상코드는 자동완성 목록에도 추가됩니다.
  • 현재 PC의 보정 X/Y는 유지됩니다.
  • 라벨 작업 파일이 아니면 "이 파일은 라벨 작업 파일이 아니에요" 알림이 뜹니다.

문제 해결 (FAQ)

인쇄했더니 바탕색(파랑/빨강)이 안 나와요.

인쇄 창의 "배경 그래픽" 을 체크하세요. (더 많은 설정 → 옵션 → 배경 그래픽)

라벨이 칸에서 밀려서 찍혀요.

① 인쇄 창의 여백 '없음', 배율 '기본값(100%)' 인지 확인 → ② 그래도 밀리면 13장 정렬 테스트 인쇄로 보정 X/Y를 맞추세요.

라벨이 전체적으로 작게(또는 크게) 찍혀요.

배율이 100%가 아닌 경우입니다. 인쇄 창에서 '페이지에 맞춤'을 끄고 배율을 기본값/100% 로 하세요. 보정 X/Y로는 크기를 고칠 수 없습니다.

라벨 가장자리에 흰 틈이 생겨요.

색 번짐 값을 조금 올리세요 (예: 0.6 → 1.0mm).

라벨 가장자리에 진한 선이 칼선과 어긋나 보여요.

바깥 테두리 옵션을 끄세요.

세로로 인쇄돼요.

인쇄 창에서 레이아웃을 가로로 하세요.

현장명이 너무 작게 나와요.

현장명이 길어 칸에 맞추느라 줄어든 것입니다. 괄호 속 지역명 등 꼭 필요하지 않은 부분을 줄이면 커집니다.

어제 입력한 내용이 사라졌어요.

다른 브라우저로 열었거나, 파일 위치가 바뀌었거나, 브라우저 기록을 지운 경우입니다. 원래 쓰던 브라우저·위치로 열어 보세요. 중요한 작업은 작업 저장 으로 파일을 남겨 두세요.

미리보기에 라벨이 안 보여요.

행에 내용이 하나도 없으면 라벨로 치지 않습니다. 현장명 등 한 칸 이상 입력하세요.

이어 쓰기를 했더니 이상한 장에 칸이 비어 있어요.

시작 칸을 정한 뒤 라벨 수가 바뀌어 장 구성이 달라진 경우입니다. 미리보기 맨 위 모두 처음 칸부터 를 누르고 시작 칸을 다시 지정하세요.

블루랑 레드를 한 장에 같이 찍고 싶어요.

색상별 시트 나누기를 끄세요. 표 순서대로 섞여서 찍힙니다.

일본어 글자가 □로 나와요.

PC에 일본어 글꼴이 없는 경우입니다. Windows 설정 → 시간 및 언어 → 언어에서 일본어 보충 글꼴을 설치하세요. (일반적인 Windows 10/11에는 기본 포함)
