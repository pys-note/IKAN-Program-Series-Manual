## 1. 개요

### 1.1 무엇을 하는 프로그램인가

도면 PDF에서 **필요한 그림 부분만 골라 크게 확대해서 한 장씩 인쇄**하는 프로그램입니다. 확대한 그림 위에 작업번호, 동그라미 번호(①~⑮), 형광펜 표시를 얹어서 현장에서 보기 좋은 출력물을 만듭니다.

### 1.2 주요 특징

| 특징 | 설명 |
|---|---|
| 원본 보존 | 원본 PDF는 절대 수정하지 않습니다. 편집 내용은 별도의 작업 파일(`.pdfregions`)에 저장됩니다. |
| 영역 1개 = 출력 1장 | 인쇄 영역을 세 개 만들면 세 장이 출력됩니다. 영역마다 배율을 따로 정할 수 있습니다. |
| 사각형·다각형 영역 | L자·ㄷ자 상판처럼 필요한 부분만 꼭짓점으로 둘러싸면 바깥은 흰색으로 지워져 출력됩니다. |
| 표시 도구 | 작업번호 문구, 동그라미 번호 ①~⑮, 형광펜 선, 형광 사각형, 형광 다각형. |
| 바로 인쇄 | PDF 뷰어를 거치지 않고 프로그램에서 프린터로 바로 보냅니다. 실제 크기 100%·단면·용지 방향이 자동으로 맞춰집니다. |
| 고화질 출력 | 일반 PDF는 원본 선·글자를 그대로(벡터) 확대해 프린터 해상도로 선명하게 나오고, 스캔 도면은 자동으로 바탕을 하얗게 보정합니다. |
| 키보드 중심 | 거의 모든 기능에 단축키가 있으며 한/영 상태나 Caps Lock과 관계없이 동작합니다. |

### 1.3 용어

| 용어 | 뜻 |
|---|---|
| 원본 PDF | 불러온 도면 PDF 파일. 읽기만 합니다. |
| 인쇄 영역 | 출력할 부분을 감싼 사각형 또는 다각형. 영역 하나가 출력 한 장입니다. |
| 배율 | 원본 대비 출력 확대 비율(%). 영역마다 따로 가집니다. |
| 개체 | 페이지 위에 만든 영역·문구·번호·형광 표시를 통틀어 부르는 말. |
| 작업 파일 | 영역·문구·형광 표시를 저장한 `.pdfregions` 파일. |
| 인쇄용 PDF | 영역마다 한 장씩, 확대·표시가 반영되어 만들어진 출력 전용 PDF. |
| pt (포인트) | 크기 단위. 1pt = 1/72인치 ≈ 0.353mm. 원본 도면 기준 크기입니다. |

## 2. 설치와 실행

### 2.1 폴더 구성 (배포본)

```
도면확대인쇄_v2.6/
├─ 빌드.bat          ← 처음 한 번 더블클릭해서 실행 파일을 만듭니다
├─ build.py
├─ 빠른시작.txt
├─ 사용방법.md
├─ 소스/             ← 프로그램 소스 (app.py, core.py, ui.py, winprint.py, requirements.txt, README.md)
└─ 라이선스/
```

### 2.2 처음 설치 (한 번만)

1. Python 3.11 이상이 설치된 PC에서 **`빌드.bat`을 더블클릭**합니다.
2. 필요한 부품 설치 → 아이콘 생성 → 실행 파일 생성 순서로 진행되며 1~3분 걸립니다.
3. 끝나면 같은 폴더에 **`도면확대인쇄.exe`와 `_internal` 폴더**가 생깁니다.
4. 이후로는 `도면확대인쇄.exe`만 실행하면 됩니다.

> **주의:** 실행 파일을 다른 곳으로 옮길 때는 `_internal` 폴더를 포함한 **폴더 전체**를 함께 옮겨야 합니다.
>
> Python이 없으면 빌드.bat이 "Python is not installed" 안내를 띄우고 멈춥니다. python.org에서 Python을 설치한 뒤 다시 실행하세요.

### 2.3 실행하는 방법

| 방법 | 동작 |
|---|---|
| `도면확대인쇄.exe` 더블클릭 | 빈 화면으로 시작합니다. |
| PDF 파일을 `도면확대인쇄.exe` 아이콘에 끌어다 놓기 | 그 PDF가 열린 상태로 시작합니다. 여러 개를 한 번에 놓아도 됩니다. |
| `.pdfregions` 파일을 아이콘에 끌어다 놓기 | 그 작업이 열린 상태로 시작합니다. |
| 실행 중인 창 위로 PDF를 끌어다 놓기 | PDF가 목록에 추가됩니다 (`.pdfregions`는 작업 열기). |

### 2.4 시작 화면

PDF를 열기 전에는 가운데에 아이콘과 **PDF 추가 (Ctrl+O)** 버튼, 3단계 안내가 표시됩니다.

1. R 인쇄 영역(Shift+R 다각형)으로 그림 감싸기
2. T 작업번호 · L 형광펜 · N ①②③
3. Ctrl+P 미리보기 후 바로 인쇄

## 3. 화면 구성

```
┌ 메뉴: 파일 · 편집 · 도구 · 배율 · 보기 · 도움말 ─────────────────────────────────┐
├ 상단바: [로고] [PDF 추가][작업 열기][저장] [↶][↷]   출력 예정 N장 [단축키][PDF로 저장][인쇄] ┤
├────┬──────────────┬─────────────────────────────┬────────────────┤
│도구│ PDF·원본 페이지 │ 문서 제목 / 페이지 정보   ◀ 1/2 ▶ │  인쇄 설정       │
│막대│  (목록)        │                             │  (도구별 설정)   │
│    │               │        작업 캔버스           │  이 페이지 개체   │
│    │ [PDF 추가][빼기]│                             │                │
├────┴──────────────┴─────────────────────────────┴────────────────┤
└ 상태표시줄: [현재 도구 + 키] 도움말 문구 …            메시지   [－] 100% [＋][맞춤] ┘
```

### 3.1 상단바

| 항목 | 기능 | 단축키 |
|---|---|---|
| PDF 추가 | 도면 PDF를 불러옵니다 (여러 개 선택 가능). | Ctrl+O |
| 작업 열기 | 저장해 둔 작업 파일(`.pdfregions`)을 엽니다. | Ctrl+Shift+O |
| 저장 | 작업을 저장합니다. 한 번 저장한 뒤로는 바로 덮어씁니다. | Ctrl+S |
| ↶ / ↷ | 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 출력 예정 N장 · 용지 | 지금 만들어 둔 영역 수(= 출력 장수)와 용지를 보여줍니다. | — |
| 단축키 | 단축키 전체 목록 창을 엽니다. | F1 |
| PDF로 저장 | 인쇄용 PDF를 파일로 저장합니다. | Ctrl+E |
| **인쇄** | 미리보기 후 프린터로 바로 인쇄합니다. | Ctrl+P |

버튼에 마우스를 올리면 설명과 단축키가 말풍선으로 표시됩니다.

### 3.2 도구 막대 (왼쪽 세로)

위에서부터 **선택(V) · 영역(R) · 다각영역(Shift+R) · 문구(T) · 번호(N) · 형광펜(L) · 사각형(M) · 다각형(P) · 화면(H)** 입니다. 선택된 도구는 파란색으로 표시되며, 상태표시줄 왼쪽에 도구 이름·단축키와 사용법이 나옵니다. 각 도구는 [5장](#5-도구별-상세-사용법)에서 자세히 설명합니다.

### 3.3 PDF·원본 페이지 목록 (왼쪽)

- 불러온 PDF와 각 페이지가 트리로 표시됩니다. 오른쪽 숫자는 그 PDF/페이지에서 출력될 장수입니다.
- 영역이 있는 페이지는 파란 글씨, 없는 페이지는 흐린 글씨와 `—`로 표시됩니다.
- PDF 이름에 5자리 작업번호(예: `24117` 또는 `24117-24118`)가 있으면 이름 앞에 붙여 보여줍니다 (이미 이름이 번호로 시작하면 생략).
- 아래 **PDF 추가**, **빼기** 버튼이 있습니다. 빼기는 확인을 거치며 원본 파일은 지우지 않습니다.
- 맨 아래 안내: **출력 순서는 PDF 목록 → 원본 페이지 → 영역 번호** 순서입니다.

### 3.4 작업 캔버스 (가운데)

- 위쪽 머리글에 PDF 이름, 페이지 번호, 원본 크기(mm), 파일 위치가 표시되고 오른쪽에 **◀ 현재/전체 ▶** 페이지 이동 버튼이 있습니다.
- 가운데 어두운 바탕 위에 도면 페이지가 표시되며, 여기서 영역과 표시를 만듭니다.
- 작업 결과(영역 추가, 삭제, 복사 등)는 캔버스 위쪽에 잠깐 알림으로 표시됩니다.

### 3.5 오른쪽 설정 패널

카드 형태이며 **지금 쓰는 도구나 선택한 개체에 필요한 카드만** 나타납니다.

| 카드 | 언제 보이나 | 내용 |
|---|---|---|
| 인쇄 설정 | 항상 | 용지, 배율, 적용 버튼, 자동 축소 |
| 작업번호 · 문구 | 문구 도구(T) 또는 문구 선택 시 | 문구 입력칸, 서식 프리셋, 글자색, 크기, 굵게, 번호 +1 |
| 형광 표시 | 형광펜(L)·사각형(M)·다각형(P) 또는 형광 표시 선택 시 | 형광색, 농도, 펜 굵기 |
| 동그라미 번호 | 번호 도구(N) 또는 번호 선택 시 | ①~⑮ 버튼, 색, 크기, 다음 번호 자동, 속 채움 |
| 이 페이지 개체 | 항상 | 현재 페이지의 모든 개체 목록과 순서·복제·삭제 버튼 |

개체를 선택하면 카드 제목 옆에 **"선택 영역에 적용" / "선택 문구 편집 중" / "선택 형광 편집 중" / "선택 형광펜 편집 중" / "선택 번호 편집 중"** 표시가 붙고, 그 카드에서 바꾼 값이 선택한 개체에 바로 반영됩니다.

### 3.6 상태표시줄 (맨 아래)

- 왼쪽: 현재 도구 이름과 단축키, 그 도구의 사용 요령.
- 가운데 오른쪽: 저장 완료 같은 메시지.
- 오른쪽: 화면 배율 % 와 **축소 / 확대 / 페이지 맞춤** 버튼.

### 3.7 창 제목

`작업파일이름 — 도면 확대 인쇄` 형식이며, 저장하지 않은 변경이 있으면 앞에 **●** 가 붙습니다. 아직 저장하지 않은 새 작업은 "새 작업"으로 표시됩니다.

## 4. 빠른 시작 — 기본 작업 흐름

1. **PDF 추가** (`Ctrl+O`) — 또는 PDF를 창 위로 끌어다 놓습니다.
2. 왼쪽 목록에서 PDF와 페이지를 고릅니다 (`PgDn` / `PgUp`으로 넘기기).
3. **인쇄 영역 `R`** — 그림과 치수선을 감싸도록 드래그합니다. 드래그하는 동안 실제 인쇄 크기(mm)가 보입니다.
   필요한 부분만 잘라야 하면 **다각형 영역 `Shift+R`** 로 꼭짓점을 찍습니다.
4. **배율** — 오른쪽 배율 칸에 숫자를 넣거나 100/130/160/200 버튼, 또는 `,` `.` 키로 조절합니다.
5. **작업번호 `T`** — 번호를 입력하고 그림 위를 클릭합니다.
6. **형광펜 `L`** — 시작점과 끝점을 클릭해 선을 긋고, **동그라미 번호 `N`** 으로 선 옆에 ①②③을 붙입니다.
7. **인쇄 `Ctrl+P`** — 미리보기에서 프린터를 확인하고 `Enter`를 누르면 바로 인쇄됩니다.
8. 다음에 이어서 고치려면 **작업 저장 `Ctrl+S`**.

## 5. 도구별 상세 사용법

### 5.1 선택 / 이동 — `V`

이미 만든 개체를 고르고, 옮기고, 크기를 바꾸는 도구입니다.

| 조작 | 결과 |
|---|---|
| 개체 클릭 | 선택 (주황 테두리). 오른쪽 카드에 그 개체의 값이 불러와집니다. |
| 빈 곳 클릭 | 선택 해제 |
| 개체를 드래그 | 이동. 상태표시줄에 이동 거리(mm)가 표시됩니다. 페이지 밖으로는 나가지 않습니다. |
| 모서리·변의 흰 점 드래그 | 크기 조절 (사각형 영역, 형광 사각형·다각형) |
| 형광펜 선의 양 끝 동그라미 드래그 | 선 길이·방향 수정 (`Shift`: 수평/수직/45° 고정) |
| 다각형 영역의 꼭짓점 점 드래그 | 꼭짓점 하나씩 수정 (`Shift`: 이웃 꼭짓점과 수평/수직 맞춤) |
| 문구 더블클릭 / `F2` / `Enter` | 문구를 그 자리에서 고치기 |
| 방향키 / `Shift`+방향키 | 1pt / 10pt씩 이동 |
| 우클릭 | 개체 메뉴 ([7.6](#76-우클릭-메뉴)) |

개체가 겹쳐 있을 때는 위에 그려진 표시(문구·번호·형광)가 먼저 선택되고, 영역끼리 겹치면 더 작은 영역이 선택됩니다. 원하는 개체가 잘 안 잡히면 `Tab`으로 차례대로 고르거나 오른쪽 **이 페이지 개체** 목록에서 고르세요.

### 5.2 인쇄 영역 — `R`

출력할 부분을 사각형으로 감쌉니다. **영역 하나가 출력 한 장**입니다.

- **드래그**해서 영역을 만듭니다. 드래그하는 동안 커서 옆에 `인쇄 210×120mm · 160%` 처럼 실제 인쇄 크기와 배율이 표시되고, 용지를 넘으면 `(용지 맞춤)`이 붙은 주황 표시로 바뀝니다.
- 새 영역에는 오른쪽 **배율** 칸의 현재 값이 들어갑니다.
- 만든 직후 그 영역이 선택된 상태가 되므로, 바로 배율을 바꾸면 그 영역에 적용됩니다.
- 드래그하지 않고 **클릭만** 하면 그 자리의 기존 개체를 선택합니다.
- 영역 왼쪽 위에는 이름표가 붙습니다: `출력 순번장 배율%` (예: `3장 160%`).
- 번호를 넣을 여백까지 영역에 포함하세요. 영역 밖의 문구·형광은 인쇄되지 않습니다.

**이름표 색의 의미**

| 색 | 의미 |
|---|---|
| 파랑 | 정상. 지정한 배율로 출력됩니다. |
| 주황 `160→142%` | 용지를 넘어서 자동으로 줄여 출력됩니다 (‘용지를 넘칠 때만 자동 축소’ 켜짐). |
| 빨강 `용지 초과` | 용지를 넘는데 자동 축소가 꺼져 있습니다. 이 상태에서는 인쇄가 막힙니다. |

**인쇄 범위 점선:** 영역을 선택하면 연한 파란 점선으로 그 배율에서 용지에 실제로 찍히는 범위(`A4 가로 인쇄 범위`)가 표시됩니다. 번호를 넣을 여유 공간을 가늠할 때 씁니다.

### 5.3 다각형 인쇄 영역 — `Shift+R`

L자·ㄷ자 상판처럼 **필요한 부분만 둘러싸서** 출력할 때 씁니다.

| 조작 | 결과 |
|---|---|
| 클릭 | 꼭짓점 추가 |
| `Shift` + 클릭 | 직전 꼭짓점과 수평 또는 수직으로 고정 |
| 첫 꼭짓점을 다시 클릭 / `Enter` / 우클릭 / 더블클릭 | 완성 (꼭짓점 3개 이상 필요) |
| `Backspace` | 마지막 꼭짓점 취소 |
| `Esc` | 그리기 취소 |

- 완성하면 일반 영역처럼 출력 1장이 되며 배율·용지 맞춤·출력 순서가 똑같이 적용됩니다.
- **다각형 바깥은 흰색으로 지워져 출력**됩니다. 바깥에 있는 문구·형광 표시도 출력되지 않습니다.
- 캔버스에서는 다각형 외곽선과 함께, 배율 계산 기준이 되는 바깥 사각형이 가는 점선으로 표시됩니다.
- 개체 목록에는 `◇다각형`이 붙습니다.
- `V`로 선택하면 꼭짓점마다 점이 생겨 하나씩 끌어 고칠 수 있습니다.

### 5.4 문구 (작업번호) — `T`

작업번호나 짧은 메모를 놓는 도구입니다.

1. 오른쪽 **작업번호 · 문구** 칸에 번호를 입력합니다. 비어 있을 때는 "작업번호 입력 예) 24117" 안내가 흐리게 보입니다.
2. 캔버스로 마우스를 옮기면 놓일 모습이 미리 보입니다.
3. **클릭**한 자리(문구의 왼쪽 위)에 놓입니다.

| 설정 | 설명 |
|---|---|
| 서식 프리셋 | 작업번호·빨강 굵게(24pt) / 작업번호·검정 굵게(24pt) / 작업번호·초록 굵게(24pt) / 작은 메모(14pt, 보통) / 주의·빨강(18pt 굵게) |
| 글자색 | 빨강·검정·초록·파랑 (문구 도구에서 숫자키 `1`~`4`) |
| 크기 pt | 6~100 |
| 굵게 | 켬/끔 |
| 놓을 때마다 번호 +1 | 켜면 놓을 때마다 마지막 숫자가 1씩 올라갑니다 (24117 → 24118). 앞자리 0은 유지됩니다 (007 → 008). |

- 문구를 고치려면 `V`로 선택해서 **더블클릭** 또는 `F2` → 입력 → `Enter`(확정) / `Esc`(취소).
- 문구 도구로 놓은 직후에는 선택되지 않습니다. 그래서 입력칸을 다음 번호로 바꿔도 방금 놓은 문구는 그대로 남습니다.
- 입력칸에 커서가 있을 때는 글자가 입력되므로 한 글자 단축키가 동작하지 않습니다. `Esc`나 `Enter`로 입력칸을 빠져나온 뒤 쓰세요.

### 5.5 동그라미 번호 — `N`

형광펜 선 옆 등에 **①~⑮** 번호를 붙이는 도구입니다.

- **클릭한 자리가 동그라미의 중심**이 됩니다. 마우스를 따라 다음에 놓일 번호가 미리 보입니다.
- 오른쪽 **동그라미 번호** 카드의 ①~⑮ 버튼으로 번호를 고릅니다.
- **놓을 때마다 다음 번호**(기본 켜짐): ① 놓고 → ② 놓고 → … 자동으로 넘어갑니다. ⑮에서는 더 넘어가지 않습니다.
- **숫자키로 바로 고르기**: `7` → ⑦. `1`을 누르고 0.9초 안에 `0`~`5`를 누르면 ⑩~⑮.
- `[` `]`: 이전 / 다음 번호.
- **이미 놓은 번호는 버튼이 초록색**으로 바뀌고, 카드 아래에 "이 페이지에 놓은 번호"가 나열됩니다. 같은 번호를 또 놓으면 겹친다는 알림이 뜹니다 (놓는 것은 허용됩니다).
- 색: 빨강·검정·초록·파랑 / 크기: 동그라미 지름 8~80pt (기본 22pt) / **속 채움**: 색 원 안에 흰 숫자.
- 기본 모양은 흰 바탕 동그라미라 형광펜이나 도면 선 위에 놓여도 숫자가 잘 읽힙니다.
- 놓은 번호는 `V`로 선택한 뒤 숫자키로 번호를 바꾸고, 방향키로 옮기고, 카드에서 크기·색을 고칠 수 있습니다.

> 번호 도구(N)가 선택되어 있거나 번호를 선택한 상태에서는 숫자키가 **번호**를 고르고, `[` `]`가 **이전/다음 번호**가 됩니다. 다른 상황에서는 숫자 `1`~`4`가 색, `[` `]`가 형광펜 굵기입니다.

### 5.6 형광펜 선 — `L`

직선 형광펜을 긋는 도구입니다. 도면에서 형광 표시는 대부분 직선이라 가장 자주 씁니다.

| 조작 | 결과 |
|---|---|
| 시작점 클릭 → 끝점 클릭 | 설정한 굵기로 선이 그어집니다. |
| 누른 채 드래그 후 놓기 | 같은 결과 |
| 거의 수평·수직(3° 이내) | 자동으로 반듯하게 맞춰집니다. |
| `Shift` | 수평 / 수직 / 45°로 고정 |
| `[` / `]` | 펜 굵기 −1pt / +1pt |
| `Shift+[` / `Shift+]` | 펜 굵기 −5pt / +5pt |
| `1`~`4` | 형광색 노랑 / 연두 / 분홍 / 하늘 |
| `Esc` / `Backspace` / 우클릭 | 그리던 선 취소 |

- 긋는 동안 끝점 옆에 `14pt · 50mm · 수평`처럼 굵기·길이·방향이 표시됩니다.
- 다 그은 선은 **선택되지 않은 상태**로 남습니다. 그래서 굵기나 색을 바꾸면 다음에 그을 선에만 적용되고, 이미 그은 선은 그대로입니다.
- 이미 그은 선을 고치려면 `V`로 선택 → `[` `]`로 그 선의 굵기 변경, 양 끝 동그라미를 끌어 길이·방향 변경.
- 오른쪽 **형광 표시** 카드: 형광색, 농도(15~80%), 펜 굵기(1~80pt, 6/10/14/20 바로가기 버튼).

### 5.7 형광 사각형 — `M`

넓은 면을 형광으로 칠할 때 씁니다.

- **드래그**해서 사각형을 만듭니다. 클릭만 하면 기존 개체를 선택합니다.
- 숫자 `1`~`4`로 형광색을 바꿉니다.
- 만든 직후에는 선택되지 않으므로, 색을 바꾸면 다음 사각형에 적용됩니다.
- `V`로 선택하면 모서리 점으로 크기를 조절할 수 있습니다.

### 5.8 형광 다각형 — `P`

점선 안쪽처럼 모양이 복잡한 면을 칠할 때 씁니다. 조작은 다각형 영역과 같습니다: 클릭으로 꼭짓점, `Shift`는 수평/수직, 첫 점 다시 클릭·`Enter`·우클릭·더블클릭으로 완성, `Backspace` 한 점 취소, `Esc` 취소.

> **형광 표시의 원리:** 형광은 아래 그림과 곱하기(Multiply) 방식으로 겹쳐져서, 검정 선과 글자는 형광 아래에서도 검정 그대로 선명하게 보입니다.

### 5.9 화면 이동 — `H`

드래그해서 화면을 옮깁니다. 다른 도구를 쓰는 중에도 **`Space`를 누른 채 드래그** 또는 **마우스 휠 버튼 드래그**로 잠깐 이동할 수 있습니다.

## 6. 인쇄 설정 — 용지·배율

오른쪽 **인쇄 설정** 카드에서 정합니다.

### 6.1 용지

**A4 가로 · A4 세로 · A3 가로 · A3 세로** 중 하나를 고릅니다. 모든 출력 장에 같은 용지가 쓰입니다. 용지 가장자리 여백은 6.35mm입니다.

### 6.2 배율

- 숫자 칸(10~500%, 5씩 증감)에 직접 입력하거나 **100 / 130 / 160 / 200** 바로가기 버튼을 누릅니다. 기본값은 160%입니다.
- **영역을 선택한 상태**에서는 그 영역의 배율이 표시되고, 바꾸면 그 영역에 바로 적용됩니다 (카드에 "선택 영역에 적용" 표시).
- 아무것도 선택하지 않았을 때는 **앞으로 새로 만들 영역**의 배율입니다.
- 키보드: `,` / `.` 배율 −10% / +10%, `Shift+,` / `Shift+.` −1% / +1%.
- 영역을 선택하면 카드 아래에 `원본 113×60mm → 인쇄 181×96mm`처럼 크기가 표시되고, 용지 맞춤이나 초과 여부도 함께 표시됩니다.

| 버튼 | 동작 |
|---|---|
| 이 페이지 모두 적용 | 현재 배율을 지금 페이지의 모든 영역에 적용 |
| 전체 페이지 | 현재 배율을 모든 PDF·모든 페이지의 영역에 적용 (확인 창이 뜸) |

### 6.3 용지를 넘칠 때만 자동 축소

- **켬(기본):** 지정 배율로는 용지를 넘는 영역만 들어갈 만큼 자동으로 줄입니다. 이름표가 주황(`160→142%`)으로 표시됩니다.
- **끔:** 자동으로 줄이지 않습니다. 용지를 넘는 영역은 빨간 `용지 초과`로 표시되고, 인쇄 때 어느 영역이 넘는지 목록과 함께 안내하며 인쇄를 막습니다. 잘린 출력을 막는 장치입니다.

## 7. 개체 선택과 편집

### 7.1 선택한 개체와 설정 카드의 연동

개체를 선택하면 그 개체의 값(배율, 문구 내용·크기·색, 형광색·농도·굵기, 번호·크기·색)이 오른쪽 카드에 불러와지고, 카드에서 값을 바꾸면 **선택한 개체에 바로 반영**됩니다. 같은 개체를 연속으로 고친 것은 실행 취소 한 번으로 되돌아갑니다.

> 선택한 개체의 값은 다음에 새로 만들 개체의 기본값도 됩니다. 예를 들어 `24117` 문구를 선택하면 문구 입력칸에도 `24117`이 들어갑니다.

### 7.2 이동·크기·미세 조정

- 드래그로 이동, 흰 점으로 크기 조절 ([5.1](#51-선택--이동--v)).
- 방향키로 1pt, `Shift`+방향키로 10pt씩 이동. 연속 이동은 실행 취소 한 번으로 묶입니다.
- 아무것도 선택하지 않은 상태에서 방향키를 누르면 화면이 스크롤됩니다.

### 7.3 복사·붙여넣기·복제

| 기능 | 키 | 설명 |
|---|---|---|
| 복사 | `Ctrl+C` | 선택 개체를 복사 |
| 잘라내기 | `Ctrl+X` | 복사 후 삭제 |
| 붙여넣기 | `Ctrl+V` | **다른 페이지에도** 같은 위치에 붙여넣습니다. 같은 자리에 똑같은 개체가 이미 있으면 12pt 비켜서 붙습니다. |
| 복제 | `Ctrl+D` | 12pt 비켜서 복제 |

> **활용:** 페이지 구성이 같은 도면이 여러 장일 때, 한 페이지에서 영역을 잡고 `Ctrl+C` → `PgDn` → `Ctrl+V`를 반복하면 같은 위치에 영역이 빠르게 만들어집니다.

### 7.4 삭제·순서

- 삭제: `Delete` (또는 `Backspace`). 개체 목록의 **삭제** 버튼도 같습니다.
- 출력 순서: 영역을 선택하고 `Ctrl+↑` / `Ctrl+↓`, 또는 개체 목록의 ↑ / ↓ 버튼. 페이지 안의 영역 순서가 바뀌면 출력 순서도 바뀝니다.

### 7.5 차례로 고르기

`Tab` / `Shift+Tab`으로 현재 페이지의 개체를 다음 / 이전 순서로 고릅니다. 선택한 개체가 화면 밖에 있으면 화면이 따라갑니다. `Esc`는 선택 해제입니다.

### 7.6 우클릭 메뉴

개체 위에서 우클릭하면 그 개체가 선택되고 메뉴가 뜹니다.

| 대상 | 메뉴 |
|---|---|
| 문구 | 문구 고치기(F2) + 공통 |
| 영역 | 공통 + 배율 +10% / −10%, 출력 순서 앞으로 / 뒤로 |
| 형광펜 선 | 공통 + 굵게 +1pt / 가늘게 −1pt |
| 공통 | 복제, 복사, 잘라내기, 붙여넣기, 삭제 |
| 빈 곳 | 붙여넣기, 페이지 맞춤 |

다각형을 그리는 중에는 우클릭이 **완성**, 형광펜 선을 긋는 중에는 **취소**입니다.

### 7.7 이 페이지 개체 목록

현재 페이지의 개체가 아이콘과 함께 나열됩니다.

| 표시 | 예 |
|---|---|
| 영역 | `출력 3장 · 영역 1` / `160%` (용지 맞춤이면 `→ 142%`, 초과면 `용지 초과`) |
| 문구 | `24117` / `24pt` |
| 동그라미 번호 | `③ 번호 3` / `22pt` |
| 형광 | `형광 노랑` / `펜 10pt 40%`, `사각형 40%`, `6각형 40%` |

목록에서 항목을 클릭하면 캔버스에서 선택되고, 문구를 더블클릭하면 고치기가 열립니다. 아래 버튼: 영역 순서 ↑ / ↓, 복제, 삭제.

### 7.8 실행 취소

`Ctrl+Z` 실행 취소, `Ctrl+Y`(또는 `Ctrl+Shift+Z`) 다시 실행. 최근 60단계까지 기억합니다. PDF 추가·빼기도 되돌릴 수 있습니다.

## 10. 인쇄와 PDF 저장

### 10.1 두 가지 출력 방법

| 방법 | 키 | 하는 일 |
|---|---|---|
| **인쇄** | `Ctrl+P`, 상단바 **인쇄** | 인쇄용 PDF를 임시로 만들어 미리보기를 띄우고, 거기서 프린터로 바로 인쇄합니다. |
| **PDF로 저장** | `Ctrl+E`, 상단바 **PDF로 저장** | 저장 위치를 고른 뒤 인쇄용 PDF와 순서표를 만들고 미리보기를 띄웁니다. |

출력 전에 영역이 하나도 없으면 "먼저 인쇄 영역(R)을 드래그해 지정하세요" 안내가 뜹니다. 용지를 넘는 영역이 있고 자동 축소가 꺼져 있으면 해당 영역 목록과 함께 출력이 막힙니다. 만드는 동안 진행 창에 `3 / 12장`처럼 진행 상황이 표시되며, **취소(Esc)** 로 멈출 수 있습니다.

### 10.2 인쇄 미리보기 창

```
┌ 인쇄 미리보기 · N장   [파일 · 원본 n페이지 · 영역 n · 실제 배율 · 출력 방식]   [A4 가로 · 실제 크기 100% · 단면] ┐
│                                     │ 바로 인쇄                         │
│         출력될 한 장의 모습            │  프린터 [▼]   [프린터 설정…]       │
│                                     │  매수 [1] 부  /  범위 [전체][이 장만] │
│                                     │  출력 화질 [자동][선명][이미지 보정]   │
│                                     │  ☐ 선 진하게  ☑ 스캔 보정           │
│                                     │  [ 인쇄  Enter ]                   │
│                                     │  ── 파일: [PDF로 저장] [순서표] ──   │
├ [◀] 2/5 [▶]  ← → 넘기기 · Enter 인쇄 · Ctrl+S PDF 저장 · Esc 닫기 ┤
```

| 항목 | 설명 |
|---|---|
| 페이지 넘기기 | ◀ ▶ 버튼, `←` `→`, `PgUp` `PgDn`, `Home` `End`, 마우스 휠 |
| 프린터 | 이 PC에 설치된 프린터 목록. 처음엔 Windows 기본 프린터, 이후엔 마지막에 쓴 프린터가 선택됩니다. |
| 프린터 설정… | 프린터 드라이버 자체 설정 창(급지함, 인쇄 품질 등). **용지·방향·단면은 프로그램이 자동으로 고정**하므로 바꿔도 무시됩니다. |
| 매수 | 1~99부. 2부 이상이면 **한 부씩 순서대로**(1,2,3…1,2,3…) 나옵니다. |
| 범위 | **전체 N장** 또는 **(지금 보는) N번째 장만** — 한 장만 다시 뽑을 때. |
| 출력 화질 | [11장](#11-출력-화질) 참고. 바꾸면 그 자리에서 다시 만들어 미리보기가 갱신되고, 보던 장이 유지됩니다. |
| 인쇄 (`Enter` / `Ctrl+P`) | 프린터로 보냅니다. 보내는 동안 진행 막대가 보이고 버튼이 **인쇄 취소**로 바뀝니다. 다 보내면 창이 닫히고 "프린터로 N장 보냈어요" 알림이 뜹니다. |
| PDF로 저장 (`Ctrl+S`) | (Ctrl+P로 연 경우) 인쇄용 PDF를 파일로 저장. 순서표도 함께 저장됩니다. |
| PDF 열기 / 폴더 | (Ctrl+E로 연 경우) 저장한 PDF 열기 / 탐색기에서 파일 위치 열기 |
| 순서표 | 출력 순서표(HTML) 열기 |
| 닫기 | `Esc`. 인쇄를 보내는 중에는 닫히지 않으니 먼저 **인쇄 취소**를 누르세요. |

### 10.3 바로 인쇄가 보장하는 것

- **실제 크기 100%**: 프로그램이 프린터의 실제 용지 크기와 인쇄 불가 여백을 읽어서 정확한 크기로 놓습니다. PDF 뷰어처럼 "페이지에 맞춤"으로 줄어드는 일이 없습니다.
- **단면 고정**: 프린터 기본값이 양면이어도 단면으로 인쇄합니다.
- **용지·방향 자동**: A4/A3, 가로/세로를 작업 설정에 맞춰 지정합니다. 드라이버가 방향을 무시하면 프로그램이 그림을 돌려서 맞춥니다.
- **고해상도**: 프린터 해상도(최대 600dpi)로 보냅니다.
- 프린터가 해당 용지(예: A3)를 지원하지 않으면 "이 프린터 용지가 A3 가로보다 작습니다" 안내와 함께 인쇄를 취소합니다. 종이가 반쯤 나오는 일은 없습니다.
- 인쇄는 별도 작업으로 처리되므로, 프린터 드라이버에 문제가 생겨도 편집 창은 멈추지 않습니다.

> 바로 인쇄는 Windows에서만 됩니다. 설치된 프린터가 없으면 안내가 표시되고 인쇄 버튼이 비활성화되며, **PDF로 저장**은 그대로 쓸 수 있습니다.

### 10.4 PDF로 저장과 순서표

- 기본 파일 이름: 첫 PDF 이름의 작업번호를 따서 `24117-24118_확대인쇄.pdf` (번호가 없으면 원본 이름 + `_확대인쇄.pdf`).
- 저장 위치: 처음엔 원본 PDF 폴더, 이후엔 마지막으로 저장한 폴더.
- 같은 이름으로 **`.순서표.html`** 이 함께 저장됩니다. 출력 순번, PDF, 원본 페이지, 영역 번호, 실제 배율, 확인 체크칸이 표로 정리되어 있어 출력물을 정리할 때 씁니다.
- 원본 PDF 자리에 덮어쓰는 것은 막혀 있습니다.
- 바로 인쇄용 임시 PDF는 Windows 임시 폴더에 만들어지고 하루가 지나면 자동으로 지워집니다.

## 11. 출력 화질

인쇄 미리보기 오른쪽 **출력 화질**에서 정하며, 작업 파일과 프로그램 설정에 기억됩니다.

### 11.1 출력 방식

| 방식 | 내용 | 언제 |
|---|---|---|
| **자동** (기본·권장) | 페이지마다 알아서 고릅니다. 이미지가 페이지 면적의 절반 이상을 차지하면 스캔으로 보고 **이미지 보정**, 아니면 **선명**. | 대부분의 경우 |
| **선명** (원본 벡터) | 원본 PDF의 선·글자를 이미지로 바꾸지 않고 그대로 확대해서 넣습니다. 프린터 해상도로 칼같이 선명하고 파일도 작습니다. | 일반 PDF 도면 (CAD·엑셀 등에서 만든 PDF) |
| **이미지 보정** | 영역을 최종 인쇄 크기 기준 300dpi 이미지로 만들고 보정합니다. | 스캔 도면, 또는 자동이 스캔을 알아채지 못했을 때 |

미리보기 위쪽 설명에 장마다 `선명(원본 벡터)` 또는 `이미지 보정` 중 어떤 방식으로 만들었는지 표시됩니다.

### 11.2 보정 옵션

| 옵션 | 기본 | 효과 |
|---|---|---|
| **선 진하게** (흐린 회색 선·글자) | 끔 | 흰 바탕과 검정은 그대로 두고 **회색만 진하게** 합니다. 흐린 회색으로 그려진 도면에 켜세요. 선명 방식에서는 원본을 곱하기로 한 번 더 겹쳐(60% 회색 → 36%), 이미지 방식에서는 감마 보정으로 처리합니다. |
| **스캔 보정** (바탕 하얗게·선명하게) | 켬 | 이미지 방식 페이지에만 적용됩니다. 스캔 잡티 제거 → 누런/회색 바탕을 흰색으로(색별로 따로 보정해 누런 기운 제거) → 흐린 선을 검게 → 윤곽 선명하게. 끄면 스캔 원본 색 그대로 나옵니다. |

### 11.3 표시물의 화질

- **형광**은 선명한 벡터 도형으로 들어가며, 곱하기 방식이라 아래 검정 선·글자가 그대로 보입니다.
- **문구와 동그라미 번호**는 600dpi로 그려 넣습니다.
- 영역 밖(다각형 영역은 다각형 밖)은 흰색으로 덮어 인쇄되지 않습니다.

## 12. 작업 파일 저장·열기

### 12.1 저장

- **작업 저장 `Ctrl+S`**: 처음에는 저장 위치를 묻고(기본 이름 `24117-24118_도면작업.pdfregions`, 기본 위치 원본 PDF 폴더), 그 뒤로는 같은 파일에 바로 덮어씁니다.
- **다른 이름으로 저장 `Ctrl+Shift+S`**: 새 이름·위치로 저장합니다.
- 저장되는 내용: 원본 PDF의 경로와 지문(해시), 페이지 크기, 모든 영역(사각형·다각형, 배율), 문구, 동그라미 번호, 형광 표시, 용지·배율·자동 축소·출력 화질 설정.
- **원본 PDF는 작업 파일에 들어가지 않습니다.** 원본을 원래 위치에 그대로 두세요.
- 저장하지 않은 변경이 있는 채로 작업을 열거나 프로그램을 닫으면 "현재 편집 작업을 저장할까요?"(예 / 아니요 / 취소)를 묻습니다.

### 12.2 열기

`Ctrl+Shift+O`, 상단바 **작업 열기**, 또는 `.pdfregions` 파일을 창이나 실행 파일 아이콘에 끌어다 놓기. 열 때 다음을 확인합니다.

| 확인 | 문제가 있을 때 안내 |
|---|---|
| 원본 PDF가 원래 위치에 있는지 | "원본 PDF를 찾지 못했습니다. 원래 위치로 되돌려주세요." |
| 저장 후 원본이 바뀌지 않았는지 (해시 비교) | "저장 이후 원본이 바뀌었습니다." |
| 원본 페이지 수가 같은지 | "원본 페이지 수가 다릅니다." |
| 영역·다각형 좌표가 올바른지 | "영역 좌표가 올바르지 않습니다." 등 |
| 파일 크기(20MB 이하)·형식 | "작업 파일이 너무 큽니다." / "지원하지 않는 작업 파일입니다." |

출력할 때도 원본이 바뀌었는지 다시 확인합니다 ("원본이 변경되었습니다").

### 12.3 버전 호환

작업 파일 형식은 v1과 같아서 예전 작업 파일도 그대로 열립니다. 새 기능의 정보(다각형 영역, 형광펜 선, 동그라미 번호, 출력 화질)는 추가 항목으로 저장됩니다.

## 17. 문제 해결 (FAQ)

**Q. 단축키가 안 먹어요.**
작업번호 입력칸이나 숫자 칸에 커서가 있으면 글자가 입력됩니다. `Esc`를 누르거나 캔버스를 한 번 클릭한 뒤 다시 누르세요.

**Q. 인쇄물이 작게 나와요 / 잘려요.**
- 프로그램의 **인쇄** 버튼으로 바로 인쇄하면 항상 실제 크기로 나옵니다.
- PDF로 저장해서 다른 뷰어로 인쇄할 때는 반드시 **실제 크기(100%)** 를 고르세요. "페이지에 맞춤"이면 줄어듭니다.
- 배율이 용지를 넘으면 자동 축소(주황 이름표)됩니다. 그대로 크게 뽑고 싶으면 A3를 쓰거나 영역을 나누세요.

**Q. "이 프린터 용지가 A3 가로보다 작습니다"가 떠요.**
그 프린터가 A3를 지원하지 않거나 A3 용지가 설정되지 않은 것입니다. A3 프린터를 고르거나 용지를 A4로 바꾸세요.

**Q. 작업 파일을 열 때 "원본 PDF를 찾지 못했습니다" / "원본이 바뀌었습니다"가 떠요.**
작업 파일은 원본 PDF의 위치와 내용을 확인합니다. 원본을 원래 폴더·이름으로 되돌리세요. 원본이 실제로 새 버전으로 바뀌었다면 PDF를 새로 추가해서 작업해야 합니다.

**Q. 형광 아래 글씨가 안 보일까 걱정돼요.**
형광은 곱하기 방식이라 검정 선·글자는 형광 아래에서도 검정 그대로 나옵니다. 농도를 낮추면 더 연해집니다.

**Q. 스캔 도면이 너무 하얗게 날아가요 / 잡티가 남아요.**
미리보기에서 **스캔 보정**을 끄면 원본 색 그대로 나옵니다. 흐린 선만 진하게 하려면 **선 진하게**를 켜세요.

**Q. 보통 PDF인데 흐리게 나와요.**
도면 자체가 회색 선으로 그려진 경우입니다. 미리보기에서 **선 진하게**를 켜세요.

**Q. 이미 그은 형광펜 선이 굵기를 바꿔도 안 바뀌어요.**
`[` `]`와 굵기 칸은 다음에 그을 선의 설정입니다. 이미 그은 선은 `V`로 선택한 뒤 `[` `]`로 바꾸세요.

**Q. 동그라미 번호가 ⑮에서 안 넘어가요.**
번호는 ①~⑮까지입니다. ⑮ 다음은 같은 번호가 계속 놓이니 다른 번호를 직접 고르세요.

**Q. 바탕화면 아이콘이 예전 그림이에요.**
Windows가 아이콘을 저장해 두었기 때문입니다. 바로가기를 지우고 다시 만드세요.

**Q. 실행 파일을 다른 PC로 옮겼더니 안 켜져요.**
`_internal` 폴더를 함께 옮겨야 합니다. 폴더째 복사하세요.

| 의존성 | Pillow, pypdfium2, PyInstaller (빌드용) |

### 19.2 동작 방식 요약

- 원본 PDF는 메모리로 읽어서 열므로 원본 파일을 잠그지 않습니다.
- 인쇄용 PDF 만들기와 바로 인쇄는 별도 프로세스에서 실행됩니다. 무거운 작업이나 드라이버 문제가 편집 창을 멈추지 않습니다.
- 벡터 출력: 원본 페이지를 그대로 넣고 확대·배치합니다. 형광은 곱하기 방식의 벡터 도형, 문구·번호는 600dpi 투명 이미지, 영역 밖은 흰색으로 덮습니다.
- 스캔 출력: 영역만 300dpi로 만들어 잡티 제거 → 색별 레벨 보정 → (선 진하게 시) 감마 → 언샤프 순서로 보정합니다.
- 바로 인쇄: 페이지를 최대 600dpi로 띠 단위로 나눠 그려서 프린터로 보냅니다. 메모리 사용이 일정합니다.

### 19.3 점검 모드

```
도면확대인쇄.exe --self-test <샘플.pdf> <결과폴더>
```

결과 폴더의 `result.json`에 `{"ok": true}`가 나오면 실행 파일이 정상입니다. 프린터 호출이나 원본 변경은 없습니다.
