주의

CHAPTER 02

이전 버전의 자료 이어 쓰기

새 폴더에서 실행하면 포함된 초기 자료가 표시됩니다. 이전 버전에서 추가한 기록을 이어 쓰려면 다음 순서로 옮깁니다.

  1. 이전 프로그램에서 백업·복원 → 백업 파일 저장을 선택합니다.

  2. 백업 .db 파일을 별도 위치에 저장합니다.

  3. 이전 프로그램을 종료합니다.

  4. 새 ZIP을 별도 폴더에 풀고 새 프로그램을 실행합니다.

  5. 백업·복원 → 백업에서 복원에서 2번 파일을 선택합니다.

  6. 직원 수, 최근 휴가 기록, 발생·이월일수와 직원 표시 순서를 확인합니다.

간단한 방법 — 데이터 폴더 복사 (0.6.2 이후 배포 안내)

  1. 이전 프로그램을 닫고 새 ZIP을 별도 폴더에 풉니다.

  2. 이전 연차관리.exe 옆의 데이터 폴더 전체를 새 연차관리.exe 옆에 복사합니다.

  3. 새 폴더의 연차관리.exe를 실행합니다(_internal 폴더도 같은 자리에).

0.6.7을 처음 실행하면 데이터에 '야간 시간'·'직원 연결' 칸을 자동으로 추가하고, 급여 명단을 직원정보에 연결합니다(35장). 기존 기록은 그대로지만 실행 전에 데이터 폴더를 한 번 따로 백업해 두세요.

주의

확인이 끝날 때까지 이전 폴더와 백업 파일을 보관하세요. 같은 데이터 폴더를 사용하는 프로그램은 한 번에 한 창만 실행할 수 있습니다.

4.1 조회 타일과 숫자 읽는 법

표시 해석할 때 확인할 점
조회 직원 상단 직원·이름 검색 조건에 해당하는 연간 조회 대상 직원 수입니다. 월별표의 직원 수와 다를 수 있습니다.
연간 사용 선택 연도 전체의 총 사용량입니다. 현재 월만의 사용량이 아닙니다. 사용 보정도 포함합니다.

CHAPTER 05

연·월차 관리: 사람별 사용 날짜 입력

직원 한 명을 연차·반차 두 줄로 묶어 표시합니다. 연차 사용일은 파란색, 반차 사용일은 초록색 칩으로 구분됩니다. 발생일수가 없으면 미설정 표시, 잔여가 음수이면 빨간 글자로 표시됩니다.

5.1 사용일 추가

  1. 원하는 직원의 연차 또는 반차 줄을 선택합니다.

  2. 사용일 입력을 누르거나 빈 사용일 칸의 +를 더블클릭합니다.

  3. 날짜·구분·메모를 입력합니다. 날짜는 YYYY-MM-DD로 입력하거나 달력에서 선택합니다.

  4. 내용을 확인하고 저장을 누릅니다.

저장한 사용일은 날짜순으로 정리됩니다. 같은 기록이 월별 근태표와 휴가 내역에도 반영되고 잔여일수가 다시 집계됩니다. 연차는 1일, 반차는 0.5일입니다.

5.2 사용일 수정·삭제

  • 날짜 칩을 더블클릭하면 해당 기록을 수정할 수 있습니다.
  • 같은 직원·같은 날짜의 중복 기록은 저장하지 않습니다.
  • 다른 연도의 기록은 조회 연도를 바꾼 뒤 입력합니다.
  • 삭제는 휴가 내역에서 해당 기록을 선택하고 선택 삭제를 사용합니다.
  • 오른쪽 날짜가 보이지 않으면 가로 스크롤로 이동합니다.

발생·이월일수 설정과 집계 기준

연·월차 관리에서 직원을 선택하고 발생·이월 설정을 누릅니다. 이름·발생 칸을 더블클릭해도 설정할 수 있습니다.

항목 의미
발생일수 해당 연도에 회사에서 확정한 발생일수
이월일수 잔여에 더할 이월 값
사용 보정 날짜별 사용량에 추가할 조정 값
설정 메모 설정 이유나 확인 근거

계산은 다음 기준을 사용합니다.

총 사용 = 날짜별 사용 + 사용 보정
잔여 = 발생 + 이월 − 총 사용

발생일수가 없으면 잔여를 0으로 추정하지 않고 미설정으로 표시합니다. 새 연도의 발생·이월일수도 자동으로 추정하지 않습니다. 연도를 바꾸고 회사에서 확인한 값을 입력하세요. 전년도 기록은 삭제하지 않고 계속 보관합니다.

6.1 계산 예시

다음 값은 사용법 설명을 위한 예시입니다.

항목 예시 값
발생 15일
이월 2일
연차 사용 3일
반차 사용 반차 4건 = 2일
사용 보정 0.5일
총 사용 3 + 2 + 0.5 = 5.5일
잔여 15 + 2 − 5.5 = 11.5일

연차·반차 행의 날짜 합계만 더하면 5일이지만, 총 사용에는 사용 보정 0.5일도 포함됩니다. 화면의 잔여가 날짜 개수만으로 계산한 값과 다르면 이월·사용 보정을 먼저 확인하세요.

주의

발생일수에 0을 입력한 상태는 미설정과 다릅니다. 0은 실제로 설정된 값이며, 이월·사용량에 따라 잔여가 0 또는 음수가 될 수 있습니다.

  2. 조회 연도를 새 연도로 바꿉니다.

여러 직원에게 한 번에 등록

왼쪽의 휴가 등록 또는 야근 등록을 사용합니다.

  1. 이름·부서 검색과 체크 목록에서 대상을 고릅니다.

  2. 필요하면 목록 모두 또는 현재 표의 직원을 사용합니다.

  3. 날짜·구분·메모를 입력합니다.

  5. 저장을 누릅니다.

같은 날 기록이 있거나 입사 전·퇴사 후 날짜인 직원은 미리 표시됩니다. 선택 직원 중 한 명이라도 검증을 통과하지 못하면 이번 일괄 등록은 전부 저장하지 않습니다. 문제가 표시된 직원을 확인한 뒤 다시 등록하세요.

8.1 체크 목록 사용 시 확인할 점

  • 등록 창에서 고른 날짜가 상단 조회 월의 날짜와 맞는지 다시 확인합니다.
  • 이름·부서 검색으로 대상을 좁힌 뒤 체크한 인원과 오른쪽 저장 요약을 확인합니다.

  • 휴가 구분은 선택 직원 모두에게 동일하게 적용됩니다. 서로 다른 구분을 넣으려면 나누어 등록합니다.
  • 저장 오류가 표시되면 창을 닫지 않고 날짜·대상·구분을 바로잡아 다시 저장할 수 있습니다.

참고

9.2 야근 기록

9.3 휴가 내역 수정 순서

9.4 야근과 휴가의 관계

10.1 직원 정보

10.2 직원 추가 후 진행할 일

  2. 직원 정보에서 성명·부서·입사일이 정확한지 확인합니다.

재직·퇴사 필터는 오늘 날짜와 퇴사일을 기준으로 구분합니다. 과거 월을 조회할 때의 직원 구성과 현재 재직 직원 수가 다를 수 있습니다. 월별표·야근표는 가져온 월별 구성원과 기록을 이용하므로 연간 조회 대상과도 인원이 다를 수 있습니다.

  3. Alt+↑·Alt+↓로도 이동할 수 있습니다.

  4. 순서 저장을 누릅니다.

순서는 종료 후에도 유지되고 백업·복원에도 포함됩니다. 연·월차 관리, 월별표·야근표와 해당 인쇄·엑셀에 반영됩니다. 월별 구성원은 그대로이며 순서만 바뀝니다. 이후 추가한 직원은 설정된 직원들 뒤에 표시됩니다. 휴가 내역은 날짜 기준 정렬을 유지합니다.

추가 엑셀 가져오기와 확인 사항

13.1 추가 자료 가져오기

엑셀 가져오기에서 지원하는 연간대장·월별표·야근표를 선택합니다. 같은 구조의 파일을 함께 선택할 수 있습니다. 첫 연도 자료는 연간대장과 월별표를 함께 선택하세요.

  • 월별표가 있는 연도는 월별표를 사용량 기준으로 삼습니다.
  • 동일한 내용의 파일은 건너뜁니다.
  • 기존 직원·날짜·메모와 충돌하면 현재 값을 보존하고 확인 사항에 남깁니다.
  • 수정한 엑셀을 재가져와도 현재 자료 전체를 자동 교체하지 않습니다.
  • 새 파일에 없는 기록을 자동 삭제하지 않습니다.
  • 읽기나 검증이 실패하면 이번 가져오기 전체를 취소합니다.

13.2 확인 사항 처리

확인 사항에서 날짜 차이, 이름 확인, 과거 집계 보정 등을 검토합니다. 해당 항목을 선택해 확인 메모를 저장합니다.

주의

확인 처리는 휴가 기록이나 잔여일수를 바꾸지 않습니다. 실제 수정은 해당 직원·휴가·발생일수 화면에서 수행합니다. 가져온 원문 보기는 원본 값과 수식을 읽기 전용으로 보여 주며 수식을 실행하지 않습니다.

13.3 포함된 초기 자료의 기준

초기 2026년 사용량은 월별표 기준, 발생일수·입사일은 연간대장 기준입니다. 연간대장에만 있는 2026년 날짜는 중복 차감하지 않고 확인 사항에 남겼습니다. 출근·대체근무·X·첫출근 등은 근태 메모로 보존합니다. 과거 연도의 날짜 합계와 저장 집계가 다른 항목은 사용 보정과 확인 사항을 함께 확인하세요.

14.2 백업

백업·복원 → 백업 파일 저장으로 직원·휴가·야근·확인 사항·원문·표시 순서·변경 이력과 급여 자료(명단·급여대장·설정·급여 비밀번호)를 하나의 .db 파일에 보관합니다. 외장 저장장치 등 별도 위치에도 사본을 보관하세요.

프로그램 시작 시 하루 한 번, 가져오기·복원 전에는 데이터/자동백업에 자동 백업합니다. 자동 백업과 같은 PC의 데이터는 PC 고장 때 함께 손실될 수 있으므로 별도 위치의 백업도 필요합니다.

14.3 복원

주의

Q. 검색 결과와 인쇄 결과가 다릅니다.

Q. 새 버전에서 최근 입력 기록이 없습니다.

새 폴더의 초기 자료인지 확인하고 이전 버전의 백업을 복원합니다.

Q. 다른 PC로 옮긴 뒤 자료가 없습니다.

실행 파일뿐 아니라 데이터·_internal을 포함한 폴더 전체를 옮겼는지 확인합니다.

Q. 엑셀에서 고친 내용이 프로그램에 보이지 않습니다.

내보낸 엑셀과 프로그램 데이터는 자동 동기화하지 않습니다.

급여 화면 잠금과 비밀번호

급여는 민감한 정보라 급여 화면은 비밀번호로 잠겨 있습니다. 연차관리를 함께 쓰는 사람도 비밀번호를 모르면 급여를 볼 수 없습니다.

  1. 처음 급여 관리를 누르면 급여 비밀번호 정하기가 나옵니다.

  2. 4자 이상의 비밀번호를 두 칸에 똑같이 넣고 비밀번호 정하고 열기를 누릅니다.

  • 10분 동안 아무 조작이 없을 때
  • 오른쪽 위 잠그기를 눌렀을 때
  • 프로그램을 다시 실행했을 때
  • 백업에서 복원했을 때

잠겨 있는 동안에는 급여 표·인쇄·엑셀 내보내기를 쓸 수 없고, 요약 타일에는 ‘잠김’으로 나옵니다. 변경 이력에는 급여 금액을 남기지 않습니다. ‘급여 수정 · 성명’처럼 바뀐 사실만 남습니다.

  • 기타는 항상 직접 입력입니다(사내 대출 상환 등).

29.3 백업과 복원

백업 파일에는 급여 자료와 급여 비밀번호가 함께 들어갑니다(14장). 복원하면 급여 자료와 비밀번호도 백업 시점으로 돌아갑니다. 0.4.0 이하에서 만든 백업을 복원하면 급여 자료는 비어 있고, 0.5.0 백업은 입사일만 빈칸으로 복원됩니다.

급여 관리 자주 묻는 질문

Q. 급여 화면이 잠겨서 열리지 않습니다.

정한 비밀번호를 넣고 Enter를 누르세요. 10분 동안 조작이 없으면 자동으로 다시 잠깁니다. 비밀번호를 잊었다면 잠금 화면의 ‘비밀번호를 잊었을 때’로 급여 자료만 지우고 새로 시작할 수 있습니다(24장).

Q. 신입 사원의 첫 달 4대보험이 0원입니다.

정상입니다. 입사일이 1일이 아니면 그 달은 4대보험을 공제하지 않습니다. 1일 입사인데 0원이라면 급여 명단의 입사일을 확인하세요.

Q. 건강보험이 공단 고지액과 다릅니다.

프로그램은 그 달 과세 급여(또는 명단에 적은 보수월액)로 계산합니다. 고지액은 신고한 보수월액을 기준으로 하므로 다를 수 있습니다. 명단에 신고 보수월액을 적거나, 그 칸의 자동을 끄고 고지액을 넣으세요. 장기요양은 넣은 건강보험료를 기준으로 다시 계산됩니다.

Q. 요율을 새로 넣었는데 지난달 금액이 그대로입니다.

정상입니다. 저장한 급여는 요율이 바뀌어도 그대로 보관됩니다. 그 달에 새 요율을 쓰려면 작업 → 자동 공제 다시 계산을 누르세요(마감한 달은 마감 해제 후).

Q. 메뉴의 급여 관리 옆에 ‘!’나 ‘i’가 보입니다.

요율 갱신 알림입니다. ‘i’는 곧 갱신, ‘!’는 확인 필요입니다. 요율 점검에서 새 값을 넣거나 ‘바뀌지 않음 확인’을 누르면 사라집니다(28장).

Q. 상여금이 있는 달의 갑근세가 많이 나옵니다.

상여금을 그 달 급여에 더해 간이세액표를 적용하기 때문입니다. 상여금을 다른 방식으로 원천징수한다면 갑근세 칸의 자동을 끄고 직접 입력하세요.

Q. 야근 기록이 시간외수당에 자동으로 들어가나요?

계산은 자동, 반영은 직접 누를 때만 합니다. 출퇴근 기록과 야근 계산 기준으로 시간외수당(연장)·야간수당(야간 가산)을 계산하고, 급여 화면 작업 → 출퇴근 야근수당 반영에서 확인한 뒤 반영합니다(33장). 누르지 않으면 급여대장 금액은 바뀌지 않습니다.

Q. 연차관리 직원 목록과 급여 명단이 다릅니다.

0.6.6까지는 따로 관리했습니다. 0.6.7부터는 직원 관리의 직원정보 하나를 기준으로 연결됩니다. 처음 실행할 때 같은 이름끼리 자동으로 연결하고, 급여 명단에만 있던 사람은 직원으로 추가합니다(35장). 급여 명단에 ‘정보 입력 필요’가 보이면 그 사람의 급여 정보를 넣어 저장하세요.

Q. 급여 명단에 그만둔 사람이 ‘정보 입력 필요’로 보여요.

0.6.7은 퇴사일이 없는 직원을 모두 재직으로 봅니다. 직원 관리에서 그 사람의 퇴사일을 넣으면 그다음 달부터 급여대장에서 빠집니다.

Q. 시급제 직원의 기본급이 0원이고 ‘⚠ 확인’이 떠요.

근무시간을 넣기 전이라 그렇습니다. 급여대장에서 그 직원을 열어 이 달 근무시간을 입력하세요(34.3).

Q. 급여대장을 잘못 만들었습니다.

작성 중인 달이면 작업 → 이 달 급여대장 지우기 후 다시 만드세요. 마감한 달은 먼저 마감을 해제합니다.

직원 그룹 · 삭제 · 중복 합치기

31.1 직원 그룹 (0.6.0)

생산직·사무직처럼 직원을 그룹으로 나눠 조회·인쇄·엑셀 대상을 좁힙니다.

  1. 조회 막대의 그룹 관리를 엽니다.

  2. 그룹 추가로 그룹 이름을 만듭니다.

  3. 그룹을 고르고 그 그룹에 속할 직원을 클릭해 선택합니다.

  4. 그룹·소속 저장을 누릅니다.

  5. 조회 막대의 그룹 선택(전체 그룹 / 미지정 / 사용자 그룹)으로 표시 대상을 좁힙니다. 초기화는 전체 그룹으로 돌아갑니다.

  • 직원 한 명은 한 그룹에 속합니다. 다른 그룹에 넣으면 이전 소속에서 옮겨집니다. 미지정은 소속이 없는 직원입니다.
  • 그룹을 지워도 직원·휴가·급여 기록은 지우지 않고 소속만 미지정이 됩니다.
  • 그룹은 연차 조회·월별표·직원 관리와 연차 인쇄·엑셀, 급여 화면·급여 명단·급여 인쇄·엑셀에 모두 적용되고 백업에 포함됩니다.
  • 그룹을 고른 상태로 급여대장을 만들면 그 그룹의 사람으로 시작합니다. 급여대장은 그룹별 파일이 아니라 한 달에 하나이므로, 다른 그룹은 작업 → 이 달 대상자 고르기에서 그룹을 바꿔 체크해 추가합니다. 그룹 조회를 바꾸는 것만으로 급여대장의 사람·금액이 지워지지는 않습니다.
  • 0.6.7부터 급여 화면의 그룹 관리도 직원 관리의 그룹을 그대로 고칩니다(소속을 따로 지정하지 않음).

31.2 어떤 기능을 쓸까

상황 기능
잘못 추가한 직원과 그 직원의 기록을 모두 지움 직원 삭제
같은 사람이 다른 이름으로 등록되어 기록이 나뉨 중복 합치기
실제 퇴사한 직원의 과거 기록 보관 직원 수정에서 퇴사일 입력
이름만 틀림(중복 직원 없음) 직원 수정

31.3 직원 삭제 (0.6.1)

  1. 직원 관리에서 삭제할 직원을 고르고 직원 삭제를 누릅니다.

  2. 함께 지워질 발생·이월 설정, 휴가, 야근, 근태 메모, 월별 명단, 확인 사항 건수를 확인합니다.

  3. 직원 성명을 표시된 그대로 입력하고 직원과 기록 삭제 → 마지막 확인.

처리 직전에 전체 데이터를 데이터/자동백업/직원삭제전_날짜_시간.db로 자동 백업하며, 백업에 실패하면 삭제하지 않습니다. 원본 엑셀에 그 이름이 남아 있으면 다시 가져올 때 또 등록될 수 있습니다(같은 사람의 다른 이름이면 합치기를 쓰세요).

31.4 중복 합치기 (0.6.1)

  1. 직원 관리에서 없앨 중복 이름의 직원을 고르고 중복 합치기를 누릅니다.

  2. 기록을 받을 직원(계속 쓸 이름)을 고릅니다. 그룹과 관계없이 전체 직원에서 고릅니다.

  3. 두 직원의 입사일·부서·퇴사일과 옮길 기록 수를 확인합니다.

  4. 충돌이 있으면 항목마다 남길 값을 고릅니다(고르지 않은 충돌이 있으면 진행 불가).

  5. 검토한 값으로 합치기 → 마지막 창에서 없앨 이름 → 남길 이름 방향을 확인합니다.

  • 날짜가 겹치지 않는 휴가·야근·근태는 옮기고, 같은 날짜·같은 내용은 한 건으로 합칩니다(사용 일수를 두 번 세지 않음). 내용이 다르면 화면에서 고릅니다.
  • 같은 연도의 발생·이월·사용 보정은 더하지 않습니다. 다르면 한쪽을 고릅니다.
  • 남길 직원의 이름·입사일·부서·퇴사일·표시 위치를 유지하고, 없앤 직원의 정보는 메모에 덧붙입니다. 남길 직원에게 그룹이 없으면 없앤 직원의 그룹을 이어받습니다.
  • 합친 옛 이름을 기억해, 나중에 엑셀을 가져올 때 그 이름을 기존 직원에게 연결합니다.
  • 처리 직전 직원합치기전_날짜_시간.db 자동 백업. 검토 뒤 자료가 바뀌었거나 오류가 나면 전체를 취소합니다.

주의

되돌리려면 백업·복원 → 백업에서 복원으로 위 자동 백업을 고릅니다. 복원은 급여를 포함한 전체 데이터를 그 시점으로 돌립니다.

CHAPTER 32

출퇴근 기록과 야근 시간 계산

32.1 출퇴근 엑셀 가져오기 (0.6.2)

  1. 야근 기록 → 출퇴근 엑셀 가져오기에서 출퇴근 장비에서 받은 근무 기록 보고서(.xlsx)를 고릅니다.

  2. 미리보기에서 날짜·기록 시간·연결 직원을 확인합니다. 보고서 이름이 직원 이름과 다르면 그 사용자 줄을 고르고 아래 목록에서 직원을 선택합니다. 연결하지 않은 채로도 저장할 수 있고, 나중에 같은 보고서를 다시 불러와 연결할 수 있습니다.

  3. 출퇴근 기록 저장을 누릅니다. 조회 연·월을 고르고 출퇴근 기록 보기로 다시 볼 수 있습니다.

  • 하루의 모든 기록 시간을 보고서 순서대로 보관합니다. 기간 밖 날짜, 기록 한 건, 세 건 이상, 시간 순서 이상은 확인 사항으로 표시합니다.
  • 같은 사용자번호·보고서 이름·날짜를 다시 불러오면 바뀐 시간이나 직원 연결을 갱신합니다. 빈 칸은 기존 기록을 지우지 않습니다.

32.2 야근 계산 기준 (0.6.3~0.6.7)

야근 기록 → 야근 계산 기준에서 정하고 저장합니다. 저장하면 월별 표에 바로 적용되고, 이미 가져온 출퇴근 기록도 다시 계산합니다.

항목 내용
야근 시작 시각 24시간제 HH:MM (예: 18:00)
휴게시간 차감 분. 없으면 0. 야근 시작 직후에 쉰 것으로 보고 뺍니다
시간 처리 단위·방식 예: 30분 단위, 내림·반올림·올림
수당 방식 급여 시급 × 배수(권장) 또는 고정 지급단가(직원 공통 1시간 단가, 비우면 시간만 계산)
연장 시급 배수 법정 1.5
기본급 직원 월 기준시간 기본급 직원의 시급 = 그 달 기본급 ÷ 월 기준시간
야간 시작·종료 · 야간 가산 배수 기본 22:00 · 06:00 · 0.5. 배수 0이면 야간 가산을 하지 않고 급여대장 야간수당 칸도 건드리지 않음

하루 야근 시간 = 퇴근 시각 − (출근과 야근 시작 중 늦은 시각) − 휴게시간, 그다음 시간 처리 단위 적용. 0보다 작으면 0분입니다.

예시

예: 18:00 시작 · 휴게 30분 · 23:30 퇴근 → 야근 5시간, 그중 야간(22:00 이후) 1시간 30분.

32.3 야근 계산 결과 (0.6.4)

조회 연·월을 고르고 야근 계산 결과를 누르면 날짜별 야근 시간·그중 야간·수당·야간 가산과 확인 사항이 나옵니다. 다음 기록은 확인 대상으로 표시하고 계산에서 뺍니다.

  • 직원 미연결, 기간 밖, 시간이 한 건이거나 세 건 이상, 출근·퇴근 순서가 맞지 않음, 같은 직원·날짜 중복, 재직기간 밖 기록

32.4 야근 시간 직접 고치기 (0.6.6~0.6.7)

  • 월별 표에서 날짜 칸을 더블클릭하고 시:분으로 넣습니다(예: 1:30).
  • 0:00을 저장하면 그날은 야근 없음, 시간을 지우고 저장하면 출퇴근 기록의 자동 계산으로 돌아갑니다.
  • 그중 야간 시간 칸(0.6.7): 비워 두면 야근 시작 시각부터 쉬지 않고 일한 것으로 보고 자동으로 나눕니다(예: 18:00 시작 · 휴게 30분 · 8:00 입력 → 18:30~02:30, 그중 야간 4시간 30분). 자정을 넘긴 날이나 중간에 쉰 날은 실제 야간 시간을 직접 넣으세요. 야근 시간보다 길게 넣을 수 없습니다.
  • 고친 시간은 월별 표·야근 계산 결과·수당 반영에 그대로 쓰입니다.

야근수당 · 야간 가산과 급여 반영

33.1 계산 방식 (0.6.7, 근로기준법 기준)

수당 계산 급여대장 칸
연장근로 야근 시간 × 통상시급 × 연장 배수(법정 1.5) 시간외수당
야간근로 야근 중 야간 시간대(법정 22:00~06:00) 시간 × 통상시급 × 야간 가산 배수(법정 0.5) 야간수당
  • 두 가산은 겹쳐 붙습니다. 22시 이후 연장근로는 1.5 + 0.5 = 2.0배입니다.
  • 통상시급: 시급제 직원은 그 달 급여대장의 시급, 기본급 직원은 그 달 기본급 ÷ 월 기준시간. 일할·수습이 적용된 달은 일할 전 월 기본급을 씁니다.
  • 일별로 원 미만을 반올림해 월 합계를 냅니다.
  • 야간 가산은 '급여 시급 × 배수' 방식에서만 계산합니다. '고정 지급단가' 방식은 시급을 알 수 없어 야간 시간만 표시합니다.

참고

법정 배수는 기본값일 뿐입니다. 회사 규정·근로계약에 따라 배수를 바꿀 수 있으며, 프로그램이 법적 요건 충족을 판정하지는 않습니다.

33.2 급여대장에 반영하기 (0.6.4~0.6.7)

  1. 급여 화면 잠금을 풀고 그 달의 작성 중 급여대장을 엽니다.

  2. 작업 → 출퇴근 야근수당 반영…을 엽니다.

CHAPTER 34

기본급 계산 — 중도입사 일할 · 수습 90% · 시급제

34.1 중도입사 일할 (0.6.0)

입사월의 기본급은 그 달 달력일수를 분모로, 입사일부터 말일까지(입사일 포함, 주말 포함) 계산하고 원 미만을 반올림합니다.

월 기본급 ÷ 그 달 일수 × 재직 일수 — 예: 3,100,000원, 10월 16일 입사 → 3,100,000 ÷ 31 × 16 = 1,600,000원

  • 새 급여대장을 만들거나 대상자를 추가할 때 입사월에 자동 적용합니다(지급일이 아니라 급여 귀속 월 기준). 식대·수당 등 다른 지급 항목은 일할하지 않습니다.
  • 일할 계산식은 법에 하나로 정해져 있지 않습니다. 회사 규정·근로계약을 확인하세요.

34.2 수습 3개월 90% (0.6.0)

  1. 급여 명단에서 직원의 입사일과 감액 전 정상 월 기본급을 등록합니다.

  2. 직원을 고르고 수습 90% 설정 → 근로계약상 수습 기본급 90% 지급 대상 체크.

  3. 수습 종료일(기본: 입사일부터 3개월, 종료일 포함)을 확인하고 저장합니다.

수습 종료가 월 중간이면 월 기본급 ÷ 월 일수 × (수습 재직일수 × 90% + 정상 재직일수 × 100%). 예: 2026-10-16 입사, 수습 종료 2027-01-15, 월 3,100,000원 → 10월 1,440,000 · 11월 2,790,000 · 2027년 1월 2,950,000 · 2월 3,100,000원.

주의

약정 기본급의 90%와 최저임금 90% 감액 특례는 다릅니다. 최저임금 특례에는 계약기간 1년 이상, 수습 3개월 이내, 단순노무 직종 제외 등의 요건이 있습니다. 프로그램은 최저임금 적법성을 판정하지 않습니다.

  • 이미 저장한 달에 적용하려면 급여 입력창에서 감액 전 월 기본급을 넣고 월 기본급 입력 → 일할·수습 적용을 체크한 뒤 계산 근거를 확인해 저장합니다. 직접 일할한 금액을 넣을 때는 이 체크를 꺼야 두 번 깎이지 않습니다.
  • 전월 복사로 새 달을 만들 때는 보관한 정상 월 기본급으로 새 달의 조건을 다시 적용합니다. 계산 근거는 급여명세서와 엑셀 '계산근거'에 남습니다.

34.3 시급제 직원 (0.6.6~0.6.7)

  1. 급여 명단에서 직원을 수정해 시급제 직원을 체크하고 시급을 넣습니다.

  2. 월별 급여대장에서 그 직원을 열어 근무시간을 넣습니다(8시간 30분 = 8.5). 기본급 = 시급 × 근무시간.

  • 새 달의 근무시간은 0시간에서 시작합니다. 근무시간을 넣기 전에는 기본급 0원이라 급여대장에 ⚠ 확인이 표시됩니다.
  • 이미 만든 급여대장에 적용: 그 직원의 급여 수정 창에서 시급 × 근무시간으로 기본급 계산을 체크하고 저장. 0.6.7부터는 명단에서 시급제로 바꾸거나 시급을 고친 뒤 이번 달에도 반영을 고르면 작성 중인 달 기본급도 바뀝니다(넣은 근무시간은 그대로). 시급제를 끄면 명단의 기본급으로 돌아갑니다.

직원정보 하나로 명단 통합 (0.6.7)

휴가·근태표·야근 기록·급여가 모두 직원 관리의 직원정보 하나를 기준으로 움직입니다.

직원 관리에서 급여 쪽 결과
직원 추가 급여 명단에 자동 추가, 정보 입력 필요 표시 → 급여 명단에서 직책·가족 수·4대보험·기본 지급액을 넣고 저장

퇴사일 입력 퇴사한 달까지 급여대장에 들어가고 다음 달부터 빠짐(‘급여 대상’ 체크는 없어짐)

  • 급여 명단에서 추가로 넣은 사람도 직원 관리에 같은 직원으로 등록됩니다. 성명·입사일·퇴사일은 급여 명단에서 고칠 수 없고 직원 관리에서 고칩니다.
  • 급여대장을 만든 뒤 들어온 직원도, 급여 명단에서 정보를 확인해 저장하면 작성 중인 달 급여대장에 바로 들어갑니다. ‘이 달 대상자 고르기’에서 일부러 뺀 사람은 다시 넣지 않습니다.
  • 국민연금·건강보험·고용보험 적용은 사람마다 급여 명단의 4대보험 체크로 정합니다. 직원정보에서 자동 추가된 사람은 모두 체크된 상태로 시작하므로, 가입 대상이 아닌 사람(예: 대상이 아닌 외국인 직원)은 체크를 끄세요.

처음 열 때 자동으로 맞추는 내용

  1. 급여 명단의 사람을 같은 이름(띄어쓰기 무시, 합친 옛 이름 포함)의 직원과 연결합니다.

  2. 급여 명단에만 있던 급여 대상자는 직원 관리에 새 직원으로 추가합니다.

  3. 직원정보의 입사일이 비어 있으면 급여 명단의 입사일로 채웁니다.

  4. 퇴사일이 없는 직원은 모두 재직으로 보고 급여 명단에 추가합니다. 실제로 그만둔 사람이 ‘정보 입력 필요’로 보이면 직원 관리에서 퇴사일을 넣으세요. 급여대장 만들기 창에서도 확인하지 않은 사람을 알려 줍니다.
