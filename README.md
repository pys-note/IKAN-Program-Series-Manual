# 아이칸 프로그램 매뉴얼 사이트

(주) 아이칸 사내 프로그램 사용 설명서를 한곳에 모은 정적 사이트입니다.
GitHub Pages로 올려서 사내에 공유합니다.

- 홈: 프로그램 카드, 모든 매뉴얼 통합 검색, 하려는 일로 찾기
- 매뉴얼: 표지·목차·장별 구분선, 이 매뉴얼에서 찾기, 글자 크기, A4 인쇄
- 인터넷이 없어도 `docs/index.html`을 더블클릭하면 열립니다(검색 포함).

## 폴더 구조

```
ikan-manuals/
├─ build.py               사이트를 만드는 스크립트
├─ requirements.txt       필요한 파이썬 패키지
├─ src/
│  ├─ programs.json       프로그램 목록과 홈 화면 문구 ← 주로 고치는 곳
│  ├─ manuals/            매뉴얼 원본(.md, .html)      ← 주로 고치는 곳
│  │  └─ _template.md     새 매뉴얼을 쓸 때 복사해서 쓰는 양식
│  └─ figures/            글자 그림(ASCII) 대신 넣는 HTML 그림
├─ assets/
│  ├─ _base.css           디자인 가이드 공식 CSS (고치지 않음)
│  ├─ _site.css           사이트 전용 CSS
│  ├─ ikan.js             검색·목차·글자 크기
│  └─ icons/              프로그램 아이콘
└─ docs/                  만들어진 사이트 (직접 고치지 않음, build.py가 매번 새로 만듦)
```

## 처음 한 번: 준비

1. Python 3.10 이상을 설치합니다.
2. 이 폴더에서 명령 프롬프트를 열고 실행합니다.

```
pip install -r requirements.txt
```

## 매뉴얼을 고친 뒤: 사이트 다시 만들기

```
python build.py
```

마지막 줄에 `링크 문제 0개`가 나오면 정상입니다.
문제가 있으면 어느 페이지의 어떤 링크인지 표시됩니다. `python build.py --check`는 문제가 있을 때 종료 코드 1을 돌려줍니다.

만든 뒤 `docs/` 폴더까지 함께 커밋해서 올립니다.

## GitHub Pages 설정 (저장소마다 한 번)

1. 저장소 **Settings → Pages**
2. **Build and deployment → Source**: `Deploy from a branch`
3. **Branch**: `main` / 폴더 `/docs` → **Save**
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

> 사내에만 공유하려면 저장소를 Private으로 두고, 조직 플랜의 Pages 접근 제한(Private Pages)을 쓰세요.
> 무료 플랜에서는 Private 저장소의 Pages도 주소를 아는 사람은 누구나 볼 수 있습니다.

## 새 프로그램 추가하기

1. `src/manuals/_template.md`를 복사해 `src/manuals/<id>.md`로 씁니다. 인코딩은 **UTF-8**.
2. 아이콘을 `assets/icons/`에 넣습니다(SVG 권장, PNG면 256×256 이상).
3. `src/programs.json`의 `programs`에 한 덩어리를 추가합니다. 적힌 순서대로 홈에 나옵니다.

```json
{
  "id": "newapp",
  "name": "아이칸 새 프로그램",
  "en": "IKAN NEW APP",
  "app": "ik-app-workorders",
  "icon": "newapp.svg",
  "version": "1.0.0",
  "status": "ready",
  "format": "md",
  "source": "manuals/newapp.md",
  "code_keys": "combo",
  "summary": "홈 카드와 표지에 들어가는 한두 문장 설명.",
  "chips": ["Windows 10/11", "설치 파일(MSI)"],
  "quick": [
    {"t": "처음 사용하는 분", "s": "빠른 시작", "h": "#2-설치와-실행"}
  ],
  "tasks": [
    {"t": "하려는 일을 동사로", "h": "#3-장-제목"}
  ]
}
```

| 항목 | 뜻 |
|---|---|
| `id` | 주소에 쓰는 영문 이름. 사이트 주소가 `/<id>/`가 됩니다. |
| `app` | 강조색. `ik-app-workorders`(파랑) · `ik-app-plot`(청록) · `ik-app-packing`(초록) · `ik-app-labels`(빨강) 중에서 고릅니다. 새 색이 필요하면 `assets/_site.css`에 같은 모양으로 추가합니다. |
| `status` | `ready` 공개 · `draft` 준비 중(카드에 "매뉴얼 준비 중"이 표시되고, 매뉴얼 대신 안내 페이지가 열림) |
| `format` | `md` 또는 `html`(작업지시서 관리자처럼 완성된 HTML 매뉴얼) |
| `code_keys` | `` `Ctrl+S` `` 같은 코드 표기를 키 모양으로 바꿀 범위. `combo` 조합키만 · `all` 한 글자 키까지 |
| `quick` | 표지와 홈 카드의 바로가기 3개. `h`는 장·절 주소 |
| `tasks` | 홈 "하려는 일로 찾기"에 나오는 일 목록 |
| `figures` | (선택) HTML 그림(파일은 `src/figures/`에). `["코드 블록 속 말", "파일.html"]` 또는 `{"find": "코드 블록 속 말", "file": …}` → 그 글자 그림을 교체 · `{"start": "장 주소", "file": …}` → 그 장 맨 앞에 삽입 |
| `ui_brackets` | (선택) `false`면 본문의 `[글자]`를 버튼 칩으로 바꾸지 않습니다. 대괄호를 그대로 써야 하는 매뉴얼용(포장 카운트) |
| `info` | (선택) 표지 정보. 없으면 md 맨 위의 `> - 기준 버전: …` 인용문이나 `**기준 버전: …**` 굵은 줄에서 읽습니다(기준 버전·기준일·운영체제·필요 등). |

### 장·절 주소(`h`) 알아내는 법

GitHub와 같은 규칙입니다. 제목을 소문자로 바꾸고, 글자·숫자·`-`·공백 말고는 지운 뒤, 공백을 `-`로 바꿉니다.

- `## 5. 라벨 내용 입력하기` → `#5-라벨-내용-입력하기`
- `### 10-4. PDF로 저장과 순서표` → `#10-4-pdf로-저장과-순서표`
- `## 13. 프린터 위치 보정 — 정렬 테스트 인쇄` → `#13-프린터-위치-보정--정렬-테스트-인쇄` (`—`가 지워져 `-`가 두 개)

틀린 주소는 `python build.py`가 알려 줍니다.

## 기존 매뉴얼을 새 버전으로 바꿀 때

1. `src/manuals/` 의 해당 파일을 새 원본으로 덮어씁니다(파일 이름 그대로).
2. `src/programs.json` 에서 그 프로그램의 `version`, `updated`, `info`의 기준 버전을 고칩니다.
3. 장 제목이 바뀌었으면 `quick`·`tasks`의 `h`도 맞춥니다. 틀리면 `python build.py`가 알려 줍니다.
4. `python build.py` → `docs/`까지 커밋.

## 매뉴얼(.md) 쓰는 규칙

`_template.md`에 예시가 모두 들어 있습니다.

| 쓰는 법 | 사이트에서 |
|---|---|
| `## 3. 장 제목` | 장(CHAPTER 03). 장마다 왼쪽 목차와 장 구분선이 생깁니다. |
| `### 3-1. 절 제목` | 절 제목 |
| `## 목차` | 자동으로 빠집니다(왼쪽 목차가 대신함). |
| 맨 위 인용문 `> - 기준 버전: 0.1.0` | 표지 정보 칩 |
| `1. 2. 3.` 번호 목록 | 단계 상자 |
| `**[저장]**` 또는 `[저장]` | 버튼 이름 칩 |
| `**Ctrl+S**` | 키 모양 |
| `> **주의:** …` (주의·경고·중요) | 주황 주의 상자 |
| `> **팁:** …` (팁·활용·권장) | 초록 팁 상자 |
| `> **참고:** …` (그 밖) | 파란 참고 상자 |
| `> 예: …` | 예시 상자 |
| 제목에 "FAQ"·"문제 해결"·"자주 묻는"이 있는 장의 `**Q. 질문**` + 다음 줄 `A. 답` | 눌러서 펼치는 질문 상자 |
| 같은 장에서 `### 질문 제목`(…다 / …요 / …? 로 끝남) + 아래 내용 | 질문 상자. 질문 꼴이 아닌 제목은 그대로 둡니다. |
| `- [ ] 확인할 일` | 체크 상자 목록 |
| `## 1. 제목` 바로 위의 `<a id="setup"></a>` | 그 장의 주소가 `#setup`이 됩니다(없으면 제목으로 만든 주소). |
| 첫 장 앞의 문단·인용문 | 표지 아래 머리말 |
| `> **가장 중요한 구분**`(줄바꿈) 내용 | 굵은 첫 줄이 상자 제목이 됩니다. |

- `1840*660*0*700`처럼 숫자 사이의 `*`는 기울임으로 바뀌지 않게 자동 처리합니다.
- 인용문 상자를 연달아 쓸 때는 사이에 일반 문장을 한 줄 넣으세요. 붙어 있으면 한 상자로 합쳐집니다.
- 글자로 그린 표·그림(┌─┐)은 한글 폭 때문에 줄이 어긋납니다. `src/figures/`에 HTML 그림을 만들고 `figures`에 연결하면 그 자리에 그림이 들어갑니다.
