USER MANUAL · 0.1.0

아이칸 타공 위치 입력 보조

한샘 원본이나 관리자 작업 데이터로 워터젯(NcEditor)에 넣을 타공 X/Y를 계산·검토하고 USB 작업 파일로 옮깁니다. 0.1.0은 검토·시뮬레이션 단계로, 기계에 자동 입력하지 않습니다.

  • 기준 버전0.1.0
  • 기준일2026-11-12
  • 운영체제Windows 10/11 64비트
  • 단계검토·시뮬레이션 (NcEditor 자동 입력 없음)

레이저(워터젯) 제어 프로그램 Weihong Ncstudio / NcEditor에 넣을 타공 위치를, 한샘 원본 엑셀이나 작업지시서 관리자 작업 데이터에서 계산·검토하는 보조 프로그램입니다. 지금 손으로 계산하는 좌표를 미리 계산해 두고, 사람이 확인한 결과를 USB 작업 파일로 기계 PC에 옮기는 데까지 씁니다.

주의

0.1.0은 미완성 단계입니다. NcEditor에 좌표를 자동으로 입력하지 않고, 가공 파일(DXF/NCE)을 만들지 않으며, 기계를 움직이지 않습니다. "시뮬레이션"은 이 프로그램 화면 안에서 좌표를 차례로 보여 주는 기능입니다.

처음 사용하는 분되는 것 / 안 되는 것좌표 기준이 궁금한 분원점·X/Y 계산식기계 PC로 옮길 때USB 작업 저장·열기

CHAPTER 03

자료 불러오기

원본과 작업 데이터는 한 번에 하나를 고릅니다.

3-1. 원본 엑셀

작업지시서에 쓰던 한샘 원본 .xlsx를 고릅니다.

  • 상판별 씽크볼·쿡탑의 규격과 위치를 읽어 좌표를 계산합니다.
  • 품목 순서를 유지하고, 수량이 여러 개면 타공도 수량만큼 나눕니다.
  • 한 주문의 타공을 한 상판에 몰지 않고 원본의 해당 품목에 연결합니다.
  • 원본에 작업지시서 번호가 없으면 비어 있고, 수정 창에서 넣을 수 있습니다.

3-2. 작업 데이터 (.ikanwork)

관리자에서 내보낸 작업 데이터를 고릅니다.

  • '작업지시서 작성'과 '완성 엑셀 수정' 목록이 둘 다 있으면 쓸 목록을 고릅니다. 수정안·편집 초안은 자동으로 쓰지 않습니다.
  • 적용된 도면이 있으면 도면의 실제 mm 위치를 씁니다. 도면에서 지운 타공은 다시 만들지 않고 제외합니다.
  • 표의 취소선은 도면 삭제와 별개라, 도면에 남은 타공은 목록에 남깁니다.
  • 표와 저장 도면이 서로 맞지 않는 주문은 확인 대상으로 빼고 관리자에서 다시 확인하라고 안내합니다.
  • 도면이 없는 작업은 표 정보를 씁니다.

CHAPTER 04

좌표 기준

  • 각 상판의 왼쪽 아래 = (0, 0), 단위 mm.
  • 상판 방향은 도면 그대로(회전·반전하지 않음).
  • 사각 타공의 입력점은 타공의 왼쪽 아래: X = 좌시작, Y = 전면값.
  • 원형 타공의 입력점은 원의 중심.
원본 위치 기준 좌시작(X) 계산
씽크볼 우시작 상판 W − 우시작 − 타공 W
쿡탑 우센터 상판 W − 우센터 − 타공 W ÷ 2
쿡탑 좌센터 좌센터 − 타공 W ÷ 2
예시

예: 상판 1640, 쿡탑 560, 우센터 1190, 전면값 70 → X = 170, Y = 70.

  • 원형은 수정 창에서 원형을 고르고 W/H에 같은 지름을 넣습니다. 좌시작·전면값에는 원을 둘러싼 사각형의 왼쪽 아래 여백을 넣고, 표시 X/Y는 거기에 반지름을 더한 중심 좌표입니다.
  • 출력 도면의 축척·배율깨기·화면 위치로 거꾸로 계산하지 않습니다.
  • 졸리컷에 따른 실제 재단 후 치수, 직사각형이 아닌 코너, 조립 방향은 현장 자료와 비교해야 합니다.

CHAPTER 05

목록과 검토

목록에는 상태 · 작업지시서 번호 · 담당 · 오더번호 · 원본 행/반복 조각 · 타공 종류·코드 · X/Y가 나옵니다. 고르면 아래에 상판과 타공의 실제 비율 그림, 오른쪽에 규격과 계산 근거가 보입니다.

상태 뜻
검토 대기 계산은 됐지만 아직 확인하지 않음
수치 확인 필수 수치가 없거나 상판 범위를 벗어나는 등 문제 있음
확인 완료 작업자가 직접 확인 완료함
제외 좌표 출력·시뮬레이션에서 뺌

  1. 목록을 클릭하거나 Ctrl/Shift로 여러 개 고릅니다. 전체는 [전체 선택] 또는 Ctrl+A.

  2. 두 번 누르거나 [선택 수치 수정]으로 고칩니다.

  3. 맞으면 [선택 확인 완료] — 고른 항목에만 적용됩니다.

수치를 고치거나 제외/복구하면 확인 상태가 풀립니다. 주의사항이 있는 정상 수치는 한 번 더 보고 완료하세요.

CHAPTER 06

수정·제외·수기 추가

  • 수정 창: 오더번호 · 작업지시서 번호 · 코드, 상판 W/H, 타공 W/H, 좌시작 · 전면값, 형상(사각/원형).
  • 원본 파일은 고치지 않습니다. 상판 W/H 수정도 고른 타공에만 적용되니 같은 상판의 다른 타공은 따로 확인하세요.
  • X·999999 같은 비정상 수치, 좌/우시작 30mm 미만 현장타공은 제외합니다.
  • 범위 초과·규격 미등록은 좌표를 비워 두고 확인을 요청합니다(임의로 0을 넣지 않음).
  • 잘못된 수치가 남아 있으면 확인 완료·좌표 출력이 되지 않습니다.
  • [수기 타공 추가]: 자료에 없는 타공을 추가합니다. 상판을 고른 상태면 오더와 상판 크기를 기본값으로 씁니다.
  • 추가타공 수량만 있고 위치·형상이 없는 원본 항목은 확인사항에 표시만 하고 위치를 추측하지 않습니다.

CHAPTER 07

USB 작업 저장·열기

  1. [USB 작업 저장] → USB나 PC 폴더를 고릅니다. 파일은 .ikancut.

  2. 기계 PC에서 [USB 작업 열기]로 원본 없이 이어서 확인합니다.

  • 좌표 · 상판 정보 · 확인 상태 · 수기 수정 · 제외 항목 · 출처를 함께 저장합니다. 미확인 항목도 들어가므로 중간 상태를 남길 수 있습니다.
  • 이 파일은 보조 프로그램 전용입니다. NcEditor가 직접 읽는 파일이 아니며, .ikanwork와도 다른 형식입니다.
  • 형식·무결성 검사에 실패하면 지금 목록을 바꾸지 않습니다. 기존 저장 파일은 새 파일 저장이 성공한 뒤에만 바뀝니다.
  • 새 자료를 읽을 때는 저장 안 한 변경을 버릴지 묻고, 끝낼 때는 저장 · 버림 · 취소를 고릅니다.

CHAPTER 08

검토용 좌표 CSV

[선택 확인 좌표 CSV]는 고른 항목 중 확인 완료된 가공 대상만 저장합니다.

  • 고른 대상에 미확인·잘못된 수치가 있으면 먼저 확인하라고 합니다. 제외 항목은 넣지 않습니다.
  • 전부 내보내려면 전체 선택 후 실행합니다.
  • CSV는 사람이 보는 검토용 표이며 기계용 가공 파일이 아닙니다.

CHAPTER 09

화면 시뮬레이션

  1. 처음이라면 [시뮬레이션 예제]를 엽니다.

  2. [전체 선택] → [선택 확인 완료] → [선택 좌표 시뮬레이션].

  3. 상판과 X/Y가 차례로 표시됩니다. [중지] 또는 Esc로 멈춥니다.

실제 자료도 같은 방법입니다. 외부 프로그램·프린터·기계로는 아무것도 보내지 않습니다.

CHAPTER 10

문제 해결 (FAQ)

좌표가 비어 있고 '수치 확인'이에요.

범위를 벗어났거나 규격이 등록되지 않은 타공입니다. 원본·도면을 보고 수정 창에서 값을 넣은 뒤 확인 완료합니다.

관리자 도면에서 지운 타공이 목록에 없어요.

정상입니다. 적용된 도면에서 제거된 타공은 다시 만들지 않습니다. 필요하면 수기 타공으로 추가합니다.

작업 데이터를 열었더니 일부 주문이 빠져요.

표와 저장 도면이 맞지 않는 주문입니다. 관리자에서 해당 주문의 도면을 다시 확인(적용)하고 내보내세요.

기계 PC의 NcEditor에 바로 넣을 수 있나요?

아직 아닙니다. 0.1.0은 계산·검토까지입니다. 확인한 X/Y를 보며 사람이 입력합니다.

같은 상판인데 상판 크기를 고쳤더니 다른 타공은 그대로예요.

상판 W/H 수정은 고른 타공 항목에만 적용됩니다. 같은 상판의 다른 타공도 각각 고치세요.
